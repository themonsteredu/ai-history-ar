# S-Core Dream font

이 폴더의 `SCDream4.otf`부터 `SCDream8.otf`까지는 웹 화면용이며, `SCDream5.ttf`와 `SCDream9.ttf`는 PDF 내장 호환용입니다. 글꼴 파일은 수정하지 않았습니다.

- 공식 배포처: https://s-core.co.kr/company/font/
- 저작권자: (주)에스코어
- 이용 조건: 개인과 기업 사용자를 포함한 모든 사용자에게 무료 제공 및 재배포 가능
- 제한 사항: 글꼴 파일 수정 및 글꼴 자체 판매 금지

프로젝트는 웹에서는 OTF를 직접 불러오고, PDF에서는 인쇄 호환을 위해 TTF를 내장합니다.

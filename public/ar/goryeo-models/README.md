# 고려 유물 3D 자료 출처

국립중앙박물관이 공공누리 제1유형(출처 표시)으로 제공한 실제 유물의 3D 데이터입니다. 원본 OBJ의 좌표와 UV를 유지하고, 색상 텍스처를 2048px로 축소한 뒤 웹에서 이용할 수 있도록 자체 포함 GLB로 변환했습니다. 향로의 뚜껑과 몸체는 원본의 좌표를 유지해 한 파일로 묶었습니다. 표시 크기와 방향은 화면에 맞게 조정됩니다.

- `vase.glb`: [청자 상감 구름 학무늬 매병](https://www.museum.go.kr/MUSEUM/contents/M0505000000.do?relicId=1126&schM=view&searchId=search), 덕수 2182. [원본 다운로드](https://www.museum.go.kr/afile/fileDownloadById/31662)
- `incense.glb`: [청자 투각 칠보무늬 향로](https://www.museum.go.kr/MUSEUM/contents/M0505000000.do?relicId=1227&schM=view&searchId=search), 덕수 2990. [원본 다운로드](https://www.museum.go.kr/afile/fileDownloadById/31667)
- `lacquer.glb`: [나전경함](https://www.museum.go.kr/MUSEUM/contents/M0505000000.do?relicId=17027&schM=view&searchId=search), 증 9291. [원본 다운로드](https://www.museum.go.kr/afile/fileDownloadById/31682)

자료 제공: 국립중앙박물관 · [3D 데이터 이용 안내](https://www.museum.go.kr/MUSEUM/contents/M0505000000.do?cp=3&pageSize=12) · [공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do).

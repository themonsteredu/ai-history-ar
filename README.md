# AI HISTORY AR

초등학교 5학년을 위한 **삼국시대 문화유산 해설사 10차시**와 **조선시대 문화유산 해설사 10차시**를 하나의 공통 AR 엔진으로 제공하는 교육 웹앱입니다.

## 프로젝트 원칙

- 삼국시대와 조선시대는 각각 독립된 10차시 과정으로 운영한다.
- 두 과정은 공통 MOA AR Engine을 사용하되, 시대별 콘텐츠와 활동지는 분리한다.
- 학생은 AI 정보를 그대로 소비하지 않고 `의심하기 -> 확인하기 -> 만들기 -> 해설하기` 과정을 수행한다.
- 교사는 모든 차시에서 수업 내용과 준비물을 확인하고 해당 차시 활동지를 다운로드할 수 있어야 한다.
- 20개 차시 활동지는 A4 인쇄용 PDF로 제공하고, 시대별 전체 묶음 다운로드를 지원한다.
- 7차시 AR 카드 원화는 A6 규격 다운로드를 별도로 제공한다.
- 10차시에는 스탬프북, 도슨트 관찰 기록지, 부스 표지를 제공한다.
- 웹 UI와 출력 활동지의 모든 한글 글꼴은 **S-Core Dream**을 사용한다.
- 한글 문맥을 끊는 강제 줄바꿈을 금지하고 `word-break: keep-all`과 안정적인 행간을 유지한다.
- 카드 인식 실패에 대비하여 모든 AR 콘텐츠에 QR 직접 접속 경로를 제공한다.

## 과정

### 삼국시대 10차시

핵심 질문: **1500년 전 이야기, AI는 어떻게 알고 있을까?**

모둠 유산:

1. 무령왕릉
2. 백제 금동대향로
3. 첨성대
4. 신라 금관
5. 고구려 고분벽화
6. 가야 고분군

### 조선시대 10차시

핵심 질문: **우리가 아는 조선, 정말 그랬을까?**

모둠 유산:

1. 훈민정음 해례본
2. 조선왕조실록
3. 수원 화성
4. 자격루·앙부일구
5. 종묘와 종묘제례악
6. 난중일기

## 구현 영역

- 학생용 시대 선택 및 10차시 학습 흐름
- 교사용 과정 대시보드
- 차시별 교수·학습 활동, 준비물, 평가 기준, 사전 준비 안내
- 차시별 활동지 PDF 다운로드
- 시대별 활동지 전체 ZIP 다운로드
- 헤리티지 검증 공방 문항 30개씩
- AR 카드 이미지 추적, 3D/영상/음성/자막, 상호작용 미션
- AR 실전 테스트 기록 및 QR 폴백
- 10차시 교실 박물관 운영 자료

상세 사양은 `docs/CURRICULUM_IMPLEMENTATION_SPEC.md`와 `docs/WORKSHEET_CATALOG.md`에서 관리합니다.

## 현재 구현 상태

첫 번째 코드 단계가 완료되었습니다.

- Vite + React + TypeScript 앱 기반
- 삼국시대 10차시, 조선시대 10차시 전체 구조화 데이터
- 시대 선택 홈과 시대별 10차시 과정 화면
- 교사용 대시보드, 차시 검색, 차시별 40분 운영안
- 학생용·교사용 활동지 구성과 시대별 다운로드 센터
- 데스크톱·태블릿·모바일 반응형 화면과 A4 운영안 인쇄 스타일
- S-Core Dream 4~8 굵기 원본 글꼴 포함 및 실제 로딩 자동검사
- 20차시 수·차시별 40분·시대별 검증 단계·활동지 존재 여부 자동검사
- 주요 화면 브라우저 오류·가로 넘침·글꼴·경로 자동검사

활동지 화면 렌더러, PDF·ZIP 파일 생성, 검증 공방 문항, AR 엔진은 명세에 정한 순서대로 이어서 구현합니다. 현재 다운로드 센터는 자료 구성을 정확히 보여주며, 존재하지 않는 PDF를 내려받는 것처럼 표시하지 않습니다.

## 실행과 검증

```bash
pnpm install
pnpm dev
pnpm test
pnpm build
```

Windows의 Microsoft Edge가 설치된 환경에서는 개발 서버 실행 후 다음 명령으로 데스크톱·모바일 주요 경로를 확인할 수 있습니다.

```bash
pnpm verify:ui
```

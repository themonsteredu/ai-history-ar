# AI HISTORY AR

초등학교 5학년을 위한 **삼국시대 데이터·AI·AR 탐구 10차시**와 **조선시대 문화유산 해설사 10차시**를 제공하는 교육 웹앱입니다.

## 프로젝트 원칙

- 삼국시대와 조선시대는 각각 독립된 10차시 과정으로 운영한다.
- 두 과정은 인공지능과 역사 공통 AR Engine을 사용하되, 시대별 콘텐츠와 활동지는 분리한다.
- 삼국시대 학생은 `질문 -> 수집 -> 전처리 -> 시각화 -> 해석 -> 유추 -> 예측 -> AR 전시` 과정을 수행한다.
- 조선시대 학생은 AI 정보를 그대로 소비하지 않고 `의심하기 -> 확인하기 -> 만들기 -> 해설하기` 과정을 수행한다.
- 교사는 모든 차시에서 수업 내용과 준비물을 확인하고 해당 차시 활동지를 다운로드할 수 있어야 한다.
- 20개 차시 활동지는 A4 인쇄용 PDF로 제공하고, 시대별 전체 묶음 다운로드를 지원한다.
- 7차시 AR 카드 원화는 A6 규격 다운로드를 별도로 제공한다.
- 10차시에는 스탬프북, 도슨트 관찰 기록지, 부스 표지를 제공한다.
- 웹 UI와 출력 활동지의 모든 한글 글꼴은 **S-Core Dream**을 사용한다.
- 한글 문맥을 끊는 강제 줄바꿈을 금지하고 `word-break: keep-all`과 안정적인 행간을 유지한다.
- 카드 인식 실패에 대비하여 모든 AR 콘텐츠에 QR 직접 접속 경로를 제공한다.

## 과정

### 삼국시대 10차시

핵심 질문: **삼국시대 유산의 데이터를 모으면 과거를 어떻게 이해하고 미래를 어떻게 준비할 수 있을까?**

모둠 유산:

1. 무령왕릉
2. 백제 금동대향로
3. 첨성대
4. 신라 금관
5. 고구려 고분벽화
6. 가야 고분군

### 조선시대 10차시

핵심 질문: **우리가 아는 조선, 정말 그랬을까?**

모둠 유산:

1. 훈민정음 해례본
2. 조선왕조실록
3. 수원 화성
4. 자격루·앙부일구
5. 종묘와 종묘제례악
6. 난중일기

## 구현 영역

- 학생용 시대 선택 및 10차시 학습 흐름
- 삼국시대 차시별 Google Forms·Sheets, CODAP, RAWGraphs, Desmos 실행 허브
- PIN 3035 내부의 차시별 외부 도구 URL·실행 방식·결과 제출 설정
- 교사용 과정 대시보드
- 차시별 교수·학습 활동, 준비물, 평가 기준, 사전 준비 안내
- 차시별 활동지 PDF 다운로드
- 시대별 활동지 전체 ZIP 다운로드
- 헤리티지 검증 공방 문항 30개씩
- AR 카드 이미지 추적, 3D/영상/음성/자막, 상호작용 미션
- 학생이 그린 카드를 사진으로 등록해 브라우저에서 AR 표적으로 변환하는 우리 반 카드
- AR 실전 테스트 기록 및 QR 폴백
- 10차시 교실 박물관 운영 자료

상세 사양은 `docs/CURRICULUM_IMPLEMENTATION_SPEC.md`와 `docs/WORKSHEET_CATALOG.md`에서 관리합니다.

삼국시대 데이터 수집·시각화·해석·예측 활동과 외부 도구 연결 사양은 `docs/EXTERNAL_TOOL_HUB_IMPLEMENTATION_PLAN.md`에서 관리합니다.

## 현재 구현 상태

삼국시대 데이터·AI·AR 수업 허브와 기존 조선시대 과정이 함께 구현되어 있습니다.

- Vite + React + TypeScript 앱 기반
- 삼국시대 10차시, 조선시대 10차시 전체 구조화 데이터
- 삼국시대 전 차시의 역사 내용·질문/답 분리형 내장 PPT와 외부 도구 활동
- 교사용 외부 도구 설정 저장·검증·JSON 내보내기·불러오기
- 5차시 내장 데이터 정제 연습(중복·빈칸·표기 차이 6문제)과 오류를 심은 실전용 CSV
- 6차시 내장 그래프 스튜디오(학급 데이터 60건 막대그래프와 정직한 제목 고르기)
- 7차시 ‘보이는 점·모르는 점’ 그래프 해석 연습, 8차시 ‘근거 2개 → 유추 1개’ 판단 연습
- 9차시 연도별 추세와 2026년 세 시나리오로 하는 미래 예측 연습
- 10차시 부스 준비 체크리스트·관람객 질문 뽑기·30초 해설 타이머 리허설
- 학생 카드 사진을 기기 안에서 AR 표적으로 변환·저장하고 묶음 파일로 부스 태블릿에 옮기는 기능
- 6~8차시 시각화·해석·유추에 쓰는 유산별 10행씩 60행 학급 데이터셋
- 외부 도구 연결 실패에 대비한 CSV 예비 데이터
- 시대 선택 홈과 시대별 10차시 과정 화면
- 교사용 대시보드, 차시 검색, 차시별 40분 운영안
- 학생용·교사용 활동지 구성과 시대별 다운로드 센터
- 데스크톱·태블릿·모바일 반응형 화면과 A4 운영안 인쇄 스타일
- S-Core Dream 4~8 굵기 원본 글꼴 포함 및 실제 로딩 자동검사
- 20차시 수·차시별 40분·시대별 검증 단계·활동지 존재 여부 자동검사
- 주요 화면 브라우저 오류·가로 넘침·글꼴·경로 자동검사

학생 화면에는 수업 PPT와 웹앱 활동만 노출됩니다. 지도안·학생활동지·활동카드·답안·외부 도구 원본 주소는 PIN으로 잠긴 교사 화면에서 관리합니다.

## 실행과 검증

```bash
pnpm install
pnpm dev
pnpm test
pnpm build
```

Windows의 Microsoft Edge가 설치된 환경에서는 개발 서버 실행 후 다음 명령으로 데스크톱·모바일 주요 경로를 확인할 수 있습니다.

```bash
pnpm verify:ui
```

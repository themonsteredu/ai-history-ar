# AI HISTORY AR

## 운영 주소와 배포

- 정식 수업 사이트: https://ai-history-ar.vercel.app
- 통합 AR 만들기: https://ai-history-ar.vercel.app/three-kingdoms/ar-maker
- GitHub `themonsteredu/ai-history-ar`의 `main` 변경이 기존 Vercel 프로젝트로 자동 배포됩니다. 별도 Sites 주소의 배포 성공만으로 정식 사이트 반영을 완료했다고 판단하지 않습니다.
- 유물 6종의 준비된 학습용 3D 모형을 골라 점·해설·녹음을 붙이고 내 작품을 체험할 수 있습니다. 통합 제작 화면에서 도형 조립은 필요하지 않습니다. 기존에 만든 모형과 설명·녹음은 이어서 사용할 수 있습니다.
- 현재 모둠 공동 저장·전시 API는 Sites D1/R2 및 교사 인증을 사용하므로, Vercel에서는 서버 연결이 별도로 필요합니다. 기기 임시 저장과 작업 파일 보관을 공동 저장으로 안내하지 않습니다.

## 조선시대 공개수업

세종 때 과학 유물 6종(측우기·자격루·간의·앙부일구·혼천의·농사직설)으로 AR 카드와 OX 문제를 만들고, 다른 모둠 카드를 제미나이로 검증해 채택·직접 수정·제외를 정리·발표하는 1차시 수업입니다. 학생 `/joseon/open-class`, 선생님 `/teacher/joseon/open-class`. [운영 기준](docs/JOSEON_OPEN_LESSON.md)

## 현재 수업 흐름

5class와 별도로 운영합니다. 삼국시대와 조선시대 모두 근거 확인 → 표 정제 → 그래프 해석 → AR 전시의 6차시 흐름입니다. 조선시대 새 과정은 `/joseon/course/1`부터, 교사는 `/teacher/joseon/course/1`부터 시작합니다. 공개수업은 홈과 상단 메뉴에서 바로 들어갑니다.

2·3차시에는 내장 표·그래프 탐구실을 사용합니다. 확인한 문장과 출처를 입력하면 네 이야기종류별 막대그래프가 만들어집니다. 빈칸·미확인·같은 유산의 동일 문장은 집계에서 제외합니다. 유사한 표현의 중복 사실은 학생이 직접 정제합니다. 표 CSV와 그래프 PNG를 저장할 수 있습니다.

기기별 임시 저장은 공유 저장이 아닙니다. 모둠별 작업 JSON 파일을 선생님 기기에 모아 여러 파일을 선택하면 학급 그래프로 합쳐집니다. 같은 파일을 반복해서 넣어도 행이 늘어나지 않으며, 동일 행의 서로 다른 수정본은 충돌을 안내합니다.

조선 6차시 PPT와 활동지는 `public/downloads/joseon/course/`, 삼국 데이터 수업 자료는 `public/downloads/three-kingdoms/data-inquiry/`에 있습니다. 활동지는 원본 AI-L.E.A.P. 로고를 고정하고 한 활동지의 이어지는 페이지에는 머리말과 학습목표를 반복하지 않습니다. 과거 10차시 경로와 자료는 기존 수업 기록을 위해 접어 둔 이전 자료로 유지합니다.

## 이전 10차시 설계 기록

아래 내용과 과거 운영 문서는 이전 차시 구성의 기록입니다. 현재 수업은 위의 6차시 흐름과 내장 표·그래프를 우선합니다.

## 프로젝트 원칙

- 삼국시대와 조선시대는 각각 독립된 10차시 과정으로 운영한다.
- 두 과정은 인공지능과 역사 공통 AR Engine을 사용하되, 시대별 콘텐츠와 활동지는 분리한다.
- 삼국시대 학생은 `질문 -> AI 검증 -> 근거 수집 -> 정제 -> 시각화 -> 해석 -> 유추 -> AR 전시` 과정을 수행한다.
- 조선시대 학생은 `질문 -> AI 판단 -> 자료 확인 -> 표 정리 -> 그래프 -> 해석·유추 -> 녹음 AR 전시` 과정을 수행한다.
- 교사는 모든 차시에서 수업 내용과 준비물을 확인하고 해당 차시 활동지를 다운로드할 수 있어야 한다.
- 20개 차시 활동지는 A4 인쇄용 PDF로 제공하고, 시대별 전체 묶음 다운로드를 지원한다.
- 조선시대 9·10차시 AR 인식 카드는 실제 유산 사진과 이용 조건을 담은 A4 PDF 6종으로 제공한다.
- 조선시대 10차시에는 역할 나누기·다른 전시 세 곳 보기·달라진 생각 말하기를 A4 한 장으로 기록한다.
- 웹 UI와 출력 활동지의 모든 한글 글꼴은 **S-Core Dream**을 사용한다.
- 한글 문맥을 끊는 강제 줄바꿈을 금지하고 `word-break: keep-all`과 안정적인 행간을 유지한다.
- 카드 인식 실패에 대비하여 모든 AR 콘텐츠에 QR 직접 접속 경로를 제공한다.

## 과정

### 삼국시대 10차시

핵심 질문: **삼국시대 유산의 데이터를 모으면 과거를 어떻게 이해하고 미래를 어떻게 준비할 수 있을까?**

모둠 유산:

1. 무령왕릉
2. 백제 금동대향로
3. 첨성대
4. 신라 금관
5. 고구려 고분벽화
6. 가야 고분군

### 조선시대 10차시

조선시대도 A4 한 장·세 활동을 기준으로 표 → CODAP 그래프 → 해석 → 녹음 AR 전시로 이어집니다. 2차시 판단과 3차시 자료 확인은 각각 운영합니다. [조선시대 현재 운영 기준](docs/JOSEON_CONTINUITY.md)을 따릅니다.

핵심 질문: **우리가 아는 조선, 정말 그랬을까?**

모둠 유산:

1. 훈민정음 해례본
2. 조선왕조실록
3. 수원 화성
4. 자격루·앙부일구
5. 종묘와 종묘제례악
6. 난중일기

- 시대별 모둠 작업 파일과 CSV·PNG 연결, CODAP 그래프 제작 및 선택 Google Sheets 실습
- PIN 3035 내부의 차시별 외부 도구 URL·실행 방식·결과 제출 설정
- 교사용 과정 대시보드
- 차시별 교수·학습 활동, 준비물, 평가 기준, 사전 준비 안내
- 차시별 활동지 PDF 다운로드
- 시대별 활동지 전체 ZIP 다운로드
- 헤리티지 검증 공방 문항 30개씩
- AR 카드 이미지 추적, 3D/영상/음성/자막, 상호작용 미션

- 10차시 교실 박물관 운영 자료

상세 사양은 `docs/CURRICULUM_IMPLEMENTATION_SPEC.md`와 `docs/WORKSHEET_CATALOG.md`에서 관리합니다.

삼국시대 4~10차시의 현재 활동과 외부 도구 연결 사양은 `docs/THREE_KINGDOMS_CONTINUITY.md`에서 관리합니다. `docs/EXTERNAL_TOOL_HUB_IMPLEMENTATION_PLAN.md`는 이전 설계 기록입니다.

## 현재 구현 상태

삼국시대와 조선시대의 표·그래프·녹음 AR 수업 흐름이 각각 연결되어 있습니다.

- Vite + React + TypeScript 앱 기반
- 삼국시대 10차시, 조선시대 10차시 전체 구조화 데이터
- 두 시대 전 차시의 내장 수업 PPT, CODAP 실제 도움말 화면과 시대별 탐구 자료
- 교사용 외부 도구 설정 저장·검증·JSON 내보내기·불러오기
- 외부 도구 연결 실패에 대비한 CSV 예비 데이터
- 시대 선택 홈과 시대별 10차시 과정 화면
- 교사용 대시보드, 차시 검색, 차시별 40분 운영안
- 학생용·교사용 활동지 구성과 시대별 다운로드 센터
- 데스크톱·태블릿·모바일 반응형 화면과 A4 운영안 인쇄 스타일
- S-Core Dream 4~8 굵기 원본 글꼴 포함 및 실제 로딩 자동검사
- 20차시 수·차시별 40분·시대별 검증 단계·활동지 존재 여부 자동검사
- 주요 화면 브라우저 오류·가로 넘침·글꼴·경로 자동검사

학생 화면에는 수업 PPT와 웹앱 활동만 노출됩니다. 지도안·학생활동지·활동카드·답안·외부 도구 원본 주소는 PIN으로 잠긴 교사 화면에서 관리합니다.

## 실행과 검증

```bash
pnpm install
pnpm dev
pnpm test
pnpm build
```

Windows의 Microsoft Edge가 설치된 환경에서는 개발 서버 실행 후 다음 명령으로 데스크톱·모바일 주요 경로를 확인할 수 있습니다.

```bash
pnpm verify:ui
```

# AI·문화유산 데이터 탐구 — 3차시 개정안

2026-09-09 수업 실행 피드백 반영. 기존 다차시 자료의 데이터 탐구 부분을 아래 3차시로 재구성한다. AR 제작 등 다른 활동 및 웹앱의 차시 번호·저장 데이터는 변경하지 않는다.

| 차시 | 핵심 개념 | 학생 활동 | 결과물 |
|---|---|---|---|
| 1 | AI의 답과 근거, 데이터, 출처 | 기존 조사 자료를 읽고 확인한 내용을 정리 | 출처가 있는 짧은 근거 문장 |
| 2 | 행·열, 범주, 데이터 정제 | 한 행에 한 사실, 표현 통일·중복 확인 | 모둠별 정제 표 |
| 3 | 학급 통합, 빈도, 막대그래프, 해석의 한계 | 1~6모둠의 표를 합쳐 하나의 그래프 제작 | 학급 공통 그래프와 해석 |

## 운영 원칙

- 차시당 40분. 자료조사는 이미 조사한 내용을 정리하는 활동을 우선한다. 부족한 근거만 보완한다.
- 활동지는 차시당 A4 1쪽, 같은 모둠 자료를 이어서 사용한다. 빈칸은 할당량이 아니다.
- 모둠별 그래프를 요구하지 않는다. 문장 수가 적어도 데이터를 꾸며 늘리지 않는다.
- 그래프의 단위는 '정제한 근거 문장 1건'이다. 유물 수, 문화 수준, 국가의 우열을 비교하는 그래프가 아니다.
- 같은 유산의 같은 사실은 한 건만 센다. 다른 유산의 유사한 특징은 별개의 자료다.
- 이야기종류: 언제·어디 / 재료·방법 / 생김새 / 쓰임·생활. 기존 '재료·만드는 방법'을 종이·CODAP에서 짧게 표기한다.
- 그래프를 위한 유효 행은 모둠·유산·이야기종류·핵심내용·출처번호가 갖춰지고 내용이 확인된 행이다. 미확인 자료는 별도 보류한다.
- 도구는 CODAP 기본안이다. 계정 없이 시작하고 로컬 파일로 저장한다. Google Sheets, Entry, AI 서비스의 학생 로그인을 필수로 하지 않는다.
- CODAP은 실시간 공동 편집표가 아니다. 모둠 활동지 → 교사의 단일 표 입력·점검 → 학급 공통 그래프 순서로 운영한다. 학생별 조작이 필요하면 동일한 .codap 파일을 배부하고 각 기기에서 별도로 연다.
- PPT의 18건과 6·4·5·3은 설명용 연습 데이터이다. 실제 학생 조사 결과로 대체한다.

## 제작 및 산출물

- PPT: `scripts/build_three_lesson_pack.mjs`
- 인쇄물: `scripts/build_three_lesson_worksheets.py`
- 산출물: `outputs/history-three-lessons/`
- CODAP은 실제 한국어 UI에서 조작을 확인했다. 화면 캡처 전달 실패로 PPT에는 검증한 메뉴명·순서를 텍스트로 수록했다.
- 공식 안내: https://codap.concord.org/help/faqs/
- 조작 확인: CODAP v3.1.0 (2985), 2026-09-09. 일부 메뉴는 영어로 표시됨.

## 현재 삼국시대 웹앱 통합

- 삼국시대 첫 화면과 교사 대시보드의 기본 데이터 수업은 새 3차시이다.
- 수업 경로: `/three-kingdoms/data/1`, `/three-kingdoms/data/2`, `/three-kingdoms/data/3`.
- `?view=ppt`에서 해당 차시의 검수한 슬라이드 9장을 바로 넘기고 전체 화면으로 수업한다. 편집 가능한 전체 PPT도 내려받는다.
- `?view=activity`에서는 활동지 순서, 행·열 예시, 학급 전체 CODAP 그래프 절차를 안내한다. 이 화면은 종이·CODAP 활동을 안내하며 학생 입력을 자동 수집하지 않는다.
- 각 차시에서 A4 한 장짜리 학생 PDF를 제공하고, 교사 자료실은 새 PPT·활동지·안내·ZIP을 기본으로 표시한다.
- 이전 수업은 별도 접힌 영역에서 보관한다. 기존 수업 ID·저장 키·모둠 기록·AR 선행 조건은 변경하지 않았다.
- 기존 AR은 기존 모둠 프로젝트를 이어가는 경로다. 새 CODAP 학급 자료를 AR 프로젝트로 자동 변환하거나 완료 처리하지 않는다.
- 수업 링크 이동 시 기존 학생·수업 쿼리값을 유지한다.
- 새 자산은 `public/downloads/three-kingdoms/data-inquiry/` 및 `public/images/three-kingdoms/data-inquiry/`에 들어 있다. 기존 생성 스크립트의 예전 차시별 자료와 구분한다.
- 조선시대 수업 내용·자료는 변경하지 않았다.

웹앱 통합 소스는 수정했지만 운영 사이트 배포는 별도이다.

## 검수 결과

- PPT 28장 전체 렌더링·육안 확인, 한글 표시·텍스트 잘림·표 범위를 확인했다.
- 네이티브 표 12개와 편집 가능한 막대그래프 1개, 그래프 데이터 통합 문서 포함을 검사했다.
- 연습 빈도 6+4+5+3=18과 집계표·그래프 값의 일치를 확인했다.
- 학생 활동지 A4 3쪽, 교사용 안내 A4 2쪽의 모든 페이지를 렌더링하여 확인했다.
- 실제 PowerPoint 앱에서의 열기·편집은 확인하지 않았다.

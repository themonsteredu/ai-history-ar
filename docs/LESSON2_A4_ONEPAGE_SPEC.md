# 2차시 A4 한 장 활동지 고정 사양

## 목적

삼국시대와 조선시대 2차시는 AI가 만든 설명을 그대로 믿지 않고, 사실·오류·근거가 부족한 단정을 구분한 뒤 공식 자료로 확인하는 수업이다.

## 인쇄 규격

- 학생 활동지는 **모둠별 A4 세로 한 장, 한 페이지**로만 제작한다.
- 삼국시대 6종과 조선시대 6종을 각각 독립 파일로 제공한다.
- 시대별 통합 학생 PDF는 모둠별 한 장씩 총 6쪽이다.
- 한 장 안에서 1차 판단, 의심 이유, 검색어, 출처, 최종 판단, 바르게 고친 문장, 모둠 결론을 모두 완료한다.

## 학교 양식 디자인

- 상단 초록색 띠와 둥근 `2차시` 표지
- 짙은 초록색 제목·구분선
- 민트색 학습목표와 표 배경
- 베이지색 주의·판단 상자
- 학교·학년·반·이름·모둠 역할 기입란
- 한글 전체 **S-Core Dream** 적용
- 한글 강제 개행 금지, 충분한 행간과 인쇄 여백 유지

## 모둠별 콘텐츠 원칙

각 유산 활동지는 같은 양식만 반복하지 않고 담당 유산에 맞는 서로 다른 AI 문장 6개를 제공한다.

- 확인된 사실 2~3개
- 명백한 오류 2개 이상
- 근거가 부족하거나 아직 확정하기 어려운 단정 1개 이상

삼국시대는 학계 의견이 나뉘거나 자료가 부족한 내용을 `△ 보류`로 인정한다. 조선시대는 드라마·통념·과장과 기록으로 확인된 사실을 구분한다.

## 수업 흐름

1. 검색하지 않고 문장 6개를 `○·×·△·?`로 판단한다.
2. 가장 의심한 문장과 그 까닭을 선택한다.
3. 핵심 낱말 2~4개로 검색한다.
4. 국가유산청·국립박물관·국사편찬위원회·유네스코 등 신뢰 자료에서 근거를 찾는다.
5. 최종 판단과 바르게 고친 문장을 기록한다.
6. 오류 또는 보류 문장 한 개를 근거와 출처를 붙여 발표한다.

## 자동 검증 기준

생성 워크플로는 다음 항목을 실패 조건으로 검사한다.

- 모둠별 PDF가 1쪽이 아닐 때
- 페이지 크기가 A4가 아닐 때
- S-Core Dream이 PDF에 포함되지 않았을 때
- 시대별 통합 학생 PDF가 6쪽이 아닐 때
- 교사용 운영안·정답 PDF의 페이지 수가 맞지 않을 때
- 수업 PPT가 24장이 아닐 때

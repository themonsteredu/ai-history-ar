# 통합 AR 만들기

기존 4~6차시 안내와 활동은 그대로 둔다. 삼국시대에 **AR 만들기**를 추가해 차시나 데이터 작업 없이 독립적으로 제작한다.

- 학생: `/three-kingdoms/ar-maker`
- 교사: `/teacher/three-kingdoms/ar-maker`
- 기존 `/three-kingdoms/ar-studio`, 예제, 차시 자료는 변경하지 않는다.

## 한 작품, 한 작업 공간

1. 1~6모둠과 유물을 선택하면 준비된 입체 모형이 바로 열린다. 무령왕릉, 백제 금동대향로, 첨성대, 신라 금관, 고구려 고분벽화, 가야 고분군 6종을 제공한다.
2. 3~4개 설명점에서 번호를 고른 뒤 입체 모형을 짧게 눌러 위치를 정한다. 손가락으로 끌면 모형이 회전한다. 글과 30초 이내 녹음을 같은 화면에서 작성한다.
3. `사진에서 보기`로 실물 사진과 비교할 수 있다. 사진을 누르면 좌표를 모형의 정면에 투영한다. 빈 공간은 모형 앞에 표시하므로, 입체 모형으로 돌아가 원하는 표면을 눌러 위치를 확인한다.
4. 통합 제작 화면에서는 도형 조립·크기·회전 수치 편집을 요구하지 않는다. 사진/모형/체험은 동일한 작품 상태를 사용한다.
5. 퀴즈, 카드 출력, 배경음·효과음, 수업 연결, 파일 보관을 같은 페이지의 접이식 도구로 제공한다.
6. `내 작품 AR로 보기`는 수업 입장·제출·퀴즈 완성과 무관하게 현재 작품을 연다. 카메라는 해당 버튼을 눌러야 시작한다.

## 준비된 모형

실물 사진의 주요 특징을 단순화해 코드로 만든 학습용 모형이며, 실측·스캔 복원물이 아니다. 무령왕릉은 벽돌 무덤 내부, 금동대향로는 용 받침·연꽃 몸체·산 뚜껑·봉황, 첨성대는 돌층·가운데 창·꼭대기 돌, 금관은 관테·가지 장식·드리개, 고분벽화는 기존 실제 사진이 붙은 입체 전시 벽, 가야 고분군은 여러 둥근 봉분으로 표현한다.

모형은 기기에서 생성하고 재료별로 합쳐 그린다. 외부 3D 생성 서비스나 대용량 모형 다운로드가 필요하지 않다. 저장 파일은 허용된 모형 식별자와 점·설명·녹음을 포함한다. 설명점 위치는 일반 미리보기와 AR 카메라에서 동일한 정규화 좌표를 사용한다.

그래픽 가속을 사용할 수 없는 브라우저에서는 동일한 모형을 Canvas 2D로 투영해 간단한 입체 보기를 제공한다. 회전·확대·점 찍기와 벽화 사진 표시는 유지하지만 재질·빛 표현은 단순화된다. 카메라 이미지 인식에는 WebGL 지원 기기가 필요하며, 간단한 입체 보기를 AR 카메라 지원으로 안내하지 않는다.

이전 시작용 상자 모형만 자동으로 준비된 모형으로 전환한다. 학생이 수정한 모형은 유지하고, `준비된 유물 모형 사용`을 직접 선택한 경우에만 교체한다. 교체해도 설명점 ID·글·녹음·퀴즈 연결은 보존하고 위치만 다시 계산한다. 기존 차시 화면에서도 준비된 모형 파일을 열어 설명 작업을 이어갈 수 있다.

## 저장과 공유

새 제작 화면의 임시 작업은 `history-ar-maker:v1`로 분리해 기존 차시 작업을 덮어쓰지 않는다. 기기 임시 저장은 백업/공유가 아니며, 모둠 공동 저장은 기존 D1/R2 수업 API를 그대로 사용한다. 기존 JSON 작업 파일도 열 수 있다.

정식 주소는 `https://ai-history-ar.vercel.app/three-kingdoms/ar-maker`이다. Vercel의 공동 저장·전시 서버 연결은 별도 작업으로 남아 있다. 현재 정식 주소에서 확인 가능한 범위는 제작·기기 임시 저장·파일 보관과 내 작품 체험이다.

수업 공동 저장/전시 제출에는 기존 수업코드와 제출 담당 권한이 필요하다. `내 작품 체험`에는 이러한 조건이 없다. 기존 모둠 제출 기준(해설 3~4개와 녹음, 문제 2~3개)과 교사 공개 단계는 유지한다. 기존 인증·데이터베이스 스키마와 공개 범위는 변경하지 않는다.

## 검증 범위

준비된 모형 6종의 저장 형식·기하 구조·표면 좌표, 기존 작업 내용 보존, 사진 좌표 변환, 미완성 퀴즈 미리보기 제외, URL 수업 문맥 유지, 기존 저장·권한·전시·퀴즈 동작을 자동 검사한다. 실제 태블릿의 카드 인식과 녹음·재생은 실물 기기 확인이 별도로 필요하다.

# 삼국시대·조선시대 20차시 구현 사양

> 삼국시대 4~10차시는 [현재 후속 연결 기준](THREE_KINGDOMS_CONTINUITY.md)을 우선 적용합니다. 1~3차시 및 조선시대는 기존 내용을 유지합니다. 학생 활동지 경로는 같고 4~10차시 내용은 수정된 수업에 맞춰 갱신되었습니다.

## 1. 공통 수업 철학

두 과정은 다음 3막 구조를 공유한다.

1. **의심하기 (1~3차시)**: AI가 알려준 정보의 오류를 발견하고 검증 기준을 익힌다.
2. **확인하고 만들기 (4~7차시)**: 신뢰할 자료로 조사하고, 검증하고, AR 카드를 기획·제작한다.
3. **해설사 되기 (8~10차시)**: 자기 언어로 해설 콘텐츠를 만들고 교실 박물관을 연다.

앱은 결과물만 보여주는 도구가 아니라 학생이 `AI 오류 발견 -> 원본 자료 확인 -> 자기 언어로 재구성`한 흔적을 차시별로 남기도록 설계한다.

### 학생 웹 사용 원칙

- 활동지의 쓰기·모둠 선택·역할 정하기를 학생 웹 화면에 그대로 옮기지 않는다.
- 1~4차시는 교실 활동, 교사용 내장 슬라이드, 사진 카드와 인쇄 활동지를 중심으로 운영한다.
- 학생 웹은 종이로 대체하기 어려운 기능에만 사용한다: 5차시 AR 체험, 6차시 즉시 판별, 7차시 카메라 인식 점검, 8차시 음성·영상 녹화, 9차시 AR 작동 시험, 10차시 AR 박물관 관람.
- 종이에 기록해야 하는 과정중심평가 산출물은 웹에서 다시 입력시키지 않는다.

## 3. 삼국시대 10차시

핵심 질문: **1500년 전 이야기, AI는 어떻게 알고 있을까?**

### 1차시 · 1500년 전에는 무엇이 있었을까

- 목표: 삼국시대 문화유산을 찾아보고 모둠별 탐구 주제를 정한다.
- 활동: 삼국시대 연표, 유산 6종 나라 맞히기, 첫 생각 카드, 모둠 역할 배정.
- 산출물: 나의 첫 생각 카드.
- 보존 규칙: 10차시 전후 비교를 위해 교사가 회수·보관한다.
- 학생 웹: 사용하지 않는다. 교사용 내장 슬라이드, 유산 사진 카드, 인쇄 활동지로 진행한다.

### 2차시 · AI에게 물어보았습니다

- 목표: AI 답변에서 잘못되거나 확정할 수 없는 부분을 찾는다.
- 활동: 교사 준비 질문 카드와 AI 답변 출력물 읽기, 이상한 부분 밑줄, 이유 기록.
- 핵심 쟁점: 첨성대 용도, 신라 금관 착용 여부처럼 학계의 결론이 하나가 아닌 사안을 AI가 확정적으로 말하는 문제.
- 산출물: 오류 발견 기록지.

### 3차시 · 진짜인지 확인하는 방법

- 목표: 정보 검증 5단계를 익히고 적용한다.
- 검증 5단계: 출처 / 시기 / 교차 / 원본 / 보류.
- `보류`: 아직 확인되지 않은 내용은 억지로 결론 내리지 않고 '아직 모름'으로 남긴다.
- 산출물: 자료 3종 비교지와 검증 체크리스트.

### 4차시 · 우리 모둠 유산 파헤치기

- 목표: 신뢰할 수 있는 자료로 담당 유산을 조사한다.
- 자료: 국가유산청 국가유산포털, 국립중앙박물관·국립경주박물관 소장품 설명, 교사 제공 자료집.
- 조사 항목: 제작 시기 / 제작 주체와 목적 / 유산의 가치 / 현재 상태 / AI 오류의 정답 / 아직 모름 / 출처.
- 산출물: 조사 카드.

### 5차시 · AR로 만나는 문화유산

- 목표: AR 콘텐츠를 체험하고 담당 유산의 AR 표현을 기획한다.
- 기획 항목: 카드 인식 시 등장 요소 / 움직임 / 한 문장 해설 / 카드 그림 스케치 / 관람객 상호작용.
- 산출물: AR 기획서.

### 6차시 · 헤리티지 검증 공방

- 목표: 검증 기준을 적용해 진위 판별 또는 판단 보류를 수행한다.
- 앱 콘텐츠: 모둠당 5문항, 총 30문항.
- 기본 구성: 진짜 3, 가짜 2를 기준으로 하되 논쟁적 사안에는 `판단 보류` 선택지를 제공한다.
- 판별 후 근거를 반드시 기록한다.
- 통과 결과는 10차시 도슨트 자격증과 연결한다.
- 산출물: 앱 기록, 판별 근거 기록지, 검증 배지.

### 7차시 · AR 카드 만들기

- 목표: 담당 유산 특징이 드러나는 A6 AR 카드 원화를 제작한다.
- 규칙: 진한 선, 빽빽한 무늬, 강한 명암, 좌우 비대칭, 모둠 주조색 준수.
- 금지: 연한 색연필, 넓은 여백, 단조로운 면.
- 뒷면: 검증한 사실 3줄 + `AI는 이렇게 틀렸어요` 1줄 + QR 영역.
- 산출물: 카드 원화와 뒷면 문구.

### 8차시 · 30초 해설사

- 목표: 조사 결과를 30초 대본, 음성, 영상으로 제작한다.
- 대본 구조: 인사와 유산 이름 / 놀라운 사실 / `AI는 이렇게 말했지만, 사실은…` / 마무리.
- 촬영 조건: 흰 배경, 정면광, 상반신, 초상권 동의 사전 회수.
- 산출물: 해설 대본, 음성, 영상.

### 9차시 · 카드에 생명 불어넣기

- 목표: 완성된 AR 카드를 실제 조건에서 테스트하고 전시를 준비한다.
- 테스트: 각도 / 거리 / 조명 / 재인식 / 오인식 / 음성·영상 / QR 폴백.
- 리허설: 1↔4, 2↔5, 3↔6 교차 관람, 예상 질문 3개와 답변 준비.
- 산출물: AR 테스트 기록지, 예상 질문·답변지, 부스 배치 계획.

### 10차시 · 삼국시대 유산 박물관 개관

- 목표: 조사·검증한 유산을 관람객에게 자기 말로 해설한다.
- 운영: 6개 부스 자유 관람, 30초 해설, AR 체험, 스탬프, 3분 교대.
- 정리: 1차시 첫 생각 카드 반환, 현재 생각 작성, AI 활용 다짐.
- 산출물: 관람객 스탬프북, 도슨트 관찰 기록, 첫 생각 카드 전후 비교.

## 4. 조선시대 10차시

핵심 질문: **우리가 아는 조선, 정말 그랬을까?**

### 1차시 · 조선에는 무엇이 남아 있을까

- 목표: 조선시대 문화유산을 찾아보고 모둠별 탐구 주제를 정한다.
- 활동: 조선시대 연표, 유산 6종 이름 맞히기, 첫 생각 카드, 역할 배정.
- 산출물: 나의 첫 생각 카드.

### 2차시 · AI에게 물어보았습니다

- 목표: AI 답변에서 잘못된 부분을 찾는다.
- 핵심 쟁점: 장영실의 최후, 거중기의 공사 기여, 훈민정음 창제 주체 등 드라마·통념이 사실처럼 섞이는 문제.
- 산출물: 오류 발견 기록지.

### 3차시 · 진짜인지 확인하는 방법

- 목표: 정보 검증 4단계를 익히고 적용한다.
- 검증 4단계: 출처 / 시기 / 교차 / 원본.
- 산출물: 자료 3종 비교지와 검증 체크리스트.

### 4차시 · 우리 모둠 유산 파헤치기

- 목표: 신뢰할 자료로 담당 유산을 조사하고 드라마와 사실을 구분한다.
- 자료: 국가유산청 국가유산포털, 조선왕조실록 누리집, 국립고궁박물관 자료, 교사 제공 자료집.
- 조사 항목: 제작 시기 / 제작 주체와 목적 / 유산의 가치 / 현재 상태 / AI 오류의 정답 / 출처.
- 산출물: 조사 카드.

### 5차시 · AR로 만나는 문화유산

- 목표: AR 콘텐츠를 체험하고 담당 유산의 AR 표현을 기획한다.
- 산출물: AR 기획서.

### 6차시 · 헤리티지 검증 공방

- 목표: 검증 기준으로 문화유산 정보의 진위를 판별한다.
- 앱 콘텐츠: 모둠당 5문항, 총 30문항, 진짜 3·가짜 2.
- 가짜 유형: 존재하지 않는 이미지 / 연도·인물 뒤바꿈 / 다른 시대 유산 오소개.
- 산출물: 앱 기록, 판별 근거 기록지, 검증 배지.

### 7차시 · AR 카드 만들기

- 목표: 담당 유산의 특징이 드러나는 A6 AR 카드 원화를 제작한다.
- 문헌 유산 카드가 비슷해지지 않도록 조선왕조실록은 사고 건물, 난중일기는 거북선·판옥선 등 서로 다른 시각 소재를 사용한다.
- 산출물: 카드 원화와 뒷면 문구.

### 8차시 · 30초 해설사

- 목표: 조사·검증 내용을 30초 해설 대본과 음성·영상으로 제작한다.
- 필수 문장: `AI는 이렇게 말했지만, 사실은…`.
- 산출물: 해설 대본, 음성, 영상.

### 9차시 · 카드에 생명 불어넣기

- 목표: AR 인식 실전 테스트와 도슨트 리허설을 수행한다.
- 산출물: AR 테스트 기록지, 예상 질문·답변지, 부스 배치 계획.

### 10차시 · 조선시대 유산 박물관 개관

- 목표: 조사·검증한 유산을 관람객에게 자기 언어로 해설한다.
- 운영: 6개 부스, AR 카드, 스탬프, 도슨트 교대, 첫 생각 카드 전후 비교.
- 산출물: 관람객 스탬프북, 도슨트 관찰 기록, 첫 생각 카드 전후 비교.

## 7. 교사용 다운로드 원칙

- 모든 차시에 최소 1개 이상의 다운로드 자료를 제공한다.
- 활동지 원본은 데이터 기반 템플릿으로 관리하여 학생 이름, 학급, 날짜 칸을 공통 적용한다.
- 개별 PDF, 차시 묶음 PDF, 시대 전체 ZIP을 지원한다.
- 7차시는 A6 원화 템플릿을 별도 제공한다.
- 10차시는 스탬프북, 부스 표지, 도슨트 관찰 기록지를 별도 제공한다.
- 화면 미리보기와 PDF 결과가 최대한 동일하도록 인쇄 CSS와 PDF 템플릿을 함께 회귀 테스트한다.

## 8. 타이포그래피

- 모든 한글 UI 및 출력물은 `S-Core Dream`을 기본 글꼴로 사용한다.
- 본문은 4 Regular 또는 5 Medium, 제목은 6 Bold~8 Heavy 범위에서 사용한다.
- `word-break: keep-all`, `overflow-wrap: break-word`를 기본으로 한다.
- 문맥을 끊는 수동 `<br>`과 고정 높이 텍스트 박스를 사용하지 않는다.
- 노트북·태블릿·모바일에서 자연스러운 문장 단위 줄바꿈과 안정적인 행간을 유지한다.
- 인쇄 활동지는 A4 기준 최소 10.5pt, 학생 작성 안내는 11~12pt 이상을 사용한다.

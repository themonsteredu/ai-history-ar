# 조선시대 수업 운영 기준

조선시대는 1~10차시를 각각 40분으로 운영합니다. 삼국시대에서 이미 진행한 2·3차시 통합 수업은 조선시대에 적용하지 않습니다. 조선시대 2차시는 첫 판단과 확인 계획, 3차시는 실제 자료 확인과 고쳐 말하기입니다.

| 차시 | 수업 | 활동지·화면의 순서 |
|---|---|---|
| 1 | 우리 유산과 질문 정하기 | 사진에서 보이는 것 찾기 → 궁금한 것 고르기 → 우리 질문 말하기 |
| 2 | AI가 한 말 판단하기 | 내 판단 표시하기 → 의심한 문장 고르기 → 찾아볼 자료 정하기 |
| 3 | 자료에서 확인하고 고쳐 말하기 | 자료를 만든 곳 확인하기 → 읽은 자료와 비교하기 → 고친 말 한 문장 남기기 |
| 4 | 찾은 내용을 표로 정리하기 | 지난 활동 돌아보기 → 문장 세 개를 표에 담기 → 표 한 줄 설명하기 |
| 5 | 우리 표를 깔끔하게 고치기 | 우리 표 살펴보기 → 필요한 곳 고치기 → 문장 수 세고 저장하기 |
| 6 | 우리 표로 그래프 만들기 | 나누어 셀 것 고르기 → CODAP에서 그래프 만들기 → 개수 확인하고 저장하기 |
| 7 | 그래프를 보고 말하기 | 개수 읽기 → 알 수 없는 것 고르기 → 친구에게 설명하기 |
| 8 | 자료로 옛날 모습 생각하기 | 문장 두 개 고르기 → 우리 생각 한 문장 쓰기 → 아직 모르는 것 남기기 |
| 9 | 우리 목소리로 안내하는 AR 전시 | 설명할 곳 두 군데 고르기 → 녹음하고 문제 만들기 → 친구 화면에서 확인하기 |
| 10 | 우리 반 유산 박물관 열기 | 우리 역할 정하기 → 다른 전시 세 곳 보기 → 달라진 생각 말하기 |

## 교실에서 쓰는 자료

- 학생 활동지: A4 세로 한 장, 세 활동. 2차시는 여섯 모둠에 맞는 활동지 중 하나만 배부합니다. 전체 학생 묶음은 15쪽입니다.
- 교실 PPT: 모든 차시의 수업 화면에 있습니다. 6차시는 CODAP 공식 도움말의 실제 화면 7단계를 보며 따라 합니다. 예시 화면의 데이터와 학생의 CSV를 구분합니다.
- 다운로드 PPTX: 2·3차시를 위한 편집 가능한 24장. 3차시 모둠 발표 뒤 정답을 공개합니다. 원래 여섯 문장씩 총 36문장과 판단 기준은 활동지 및 발표자 노트에 보존합니다.
- 교사 진행 안내와 확인 기준: 차시마다 A4 한 장씩 제공합니다.
- AR 카드: 조선 유산 6종의 실제 사진을 원래 비율대로 출력합니다. 훈민정음 사진은 전시 복제품, 종묘 사진은 입구라는 설명을 표시합니다. 이미지별 출처와 이용 조건은 `src/content/joseon/images.json`에서 관리합니다.

## 앞뒤 차시 연결

4차시에서 서로 다른 문장 세 개와 출처를 표에 담습니다. 5차시에서 중복·분류·출처·확인 상태를 고치고, 6차시에서 그 CSV로 그래프를 만듭니다. 그래프가 세는 대상은 우리 모둠이 고른 문장 수입니다. 유산의 가치나 나라의 힘을 비교하는 수치로 사용하지 않습니다.

7차시는 실제 개수와 그래프만으로 알 수 없는 것을 말합니다. 8차시는 확인한 문장 두 개를 근거로 옛날 모습을 추론하고, 아직 모르는 점도 남깁니다. 같은 자료에서 찾은 두 문장을 독립된 두 출처로 세지 않습니다.

9차시는 사진의 설명점 두 곳에 확인한 말을 붙이고 각각 30초 이내로 녹음합니다. 관람 문제 하나를 만들고 다른 기기에서 설명과 녹음을 확인합니다. 사진 AR이 기본이며, 입체 모형이 필요하면 출처를 확인한 교사 GLB/STL 파일을 넣습니다. 삼국시대 첨성대 모형은 조선시대에 표시하지 않습니다.

10차시는 A팀 설명·B팀 관람으로 12분씩 두 차례 운영하고 역할을 바꿉니다. 관람팀은 다른 모둠 세 곳을 4분씩 방문합니다. 마지막에 2·3차시 활동지와 비교해 달라진 생각을 말합니다.

## 저장과 이전 작업 보호

4~10차시는 같은 모둠 작업 파일을 이어 씁니다. CSV·그래프 PNG·근거·해설·녹음이 작업 파일에 함께 보관됩니다. 다른 기기에서는 작업 파일을 먼저 열고 AR 카드를 비춥니다. 인쇄 카드만으로 녹음이 다른 기기에 전달되지는 않습니다.

조선시대와 삼국시대는 브라우저 저장 공간과 작업 파일의 시대 구분이 다릅니다. 이전 삼국시대 파일은 계속 열 수 있으며, 다른 시대의 파일을 잘못 불러오면 안내합니다. 기존 학생 저장 자료를 일괄 삭제하지 않습니다.

## 재생성과 확인

```bash
pnpm generate:joseon-materials
pnpm compile:joseon-ar-targets
pnpm verify:printables
pnpm test
pnpm build
```

PPTX 수정은 원본 슬라이드를 복제한 뒤 `scripts/edit_joseon_ppt.mjs`와 `scripts/joseon_ppt_copy.json`으로 상속된 문구를 수정합니다. 사진 교체 시 인식 데이터도 같은 순서로 다시 만듭니다. 사진 원본의 SHA-256과 표적 번호를 확인합니다. 실제 카메라·마이크 권한과 인식은 수업에 쓸 기기에서 점검합니다.

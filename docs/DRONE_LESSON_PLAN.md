# 드론 수업 1차시 - 오늘 바로 하는 놀이 수업안

준비 없이 오늘 들어가도 되는 **50분짜리 드론 놀이 수업**입니다.
교실이나 학원 강의실 한 칸(가로 4m 이상), 소형 실내 드론 1~2대, 학생 4~8명 기준입니다.
드론이 한 대뿐이어도 그대로 굴러가게 만들었습니다.

## 한눈에 보는 오늘 진행표

| 시간 | 무엇을 | 교사가 할 말 한 줄 |
| --- | --- | --- |
| 0~5분 | 안전 약속 3가지 | "이 세 가지 어기면 드론 착륙입니다" |
| 5~10분 | 손 풀기: 3초 호버링 | "제자리에서 3초만 떠 있게 해 보세요" |
| 10~20분 | 게임 1 - 착륙장 정확 착륙 | "접시 안에 내리면 10점" |
| 20~30분 | 게임 2 - 드론 볼링 | "종이컵 몇 개 넘기나 봅시다" |
| 30~40분 | 게임 3 - 링 통과 슬라럼 | "시간 재겠습니다, 준비!" |
| 40~47분 | 기록표 평균 내기 (수학 연결) | "우리 모둠 평균은 몇 점?" |
| 47~50분 | 시상 + 정리 | "오늘 최고 기록은..." |

배터리가 보통 7~8분이면 끝납니다. **게임 하나당 배터리 하나**라고 생각하고,
충전하는 동안 다른 모둠이 기록표를 쓰게 하면 빈 시간이 안 생깁니다.

## 0. 시작 전 5분 체크

- 드론 배터리 전부 충전 (여분 배터리 있으면 다 챙기기)
- 프로펠러 가드 장착 (실내는 무조건)
- 책상 밀어서 가운데 빈 공간 만들기
- 바닥에 착륙장 표시 (종이접시 또는 A4 용지)
- 준비물: 종이컵 10개, 훌라후프 또는 옷걸이 링 2개, 포스트잇, 초시계(휴대폰), 기록표 인쇄

## 1. 안전 약속 3가지 (5분)

칠판에 크게 써 놓고 다 같이 소리 내어 읽습니다.

1. **사람 쪽으로 날리지 않는다.** 드론 앞에 사람이 있으면 조종기에서 손을 뗀다.
2. **떨어진 드론은 선생님이 줍는다.** 학생은 프로펠러가 멈출 때까지 손대지 않는다.
3. **내 차례가 아니면 벽 쪽에 선다.** 조종하는 사람 한 명, 나머지는 관중석.

어긴 학생은 한 라운드 쉬기. 미리 말해 두면 실제로 거의 안 어깁니다.

## 2. 손 풀기 - 3초 호버링 (5분)

- 이륙 → 허리 높이에서 3초 버티기 → 착륙.
- 성공하면 다음 사람. 전원 한 번씩 돌립니다.
- 여기서 조종 감각이 잡혀야 뒤 게임이 재미있어집니다. 절대 건너뛰지 마세요.

TIP: 드론이 자꾸 한쪽으로 흐르면 학생 탓이 아니라 기체 트림 문제입니다. 선생님이 한 번 잡아 주세요.

## 3. 게임 1 - 착륙장 정확 착륙 (10분)

바닥에 종이접시 3개를 거리별로 놓습니다.

| 착륙장 | 거리 | 점수 |
| --- | --- | --- |
| 가까운 접시 | 1m | 5점 |
| 중간 접시 | 2m | 10점 |
| 먼 접시 | 3m | 20점 |

- 1인당 3번 시도, 점수 합산.
- 접시에 걸치기만 해도 절반 점수로 인정하면 분위기가 훨씬 삽니다.
- 응용: 접시 대신 A4 용지에 숫자를 크게 써 놓고, 나온 숫자끼리 더하기.

## 4. 게임 2 - 드론 볼링 (10분)

- 종이컵 10개를 볼링핀 모양(4-3-2-1)으로 세웁니다.
- 드론을 낮게 날려 컵을 쓰러뜨립니다. 착륙해서 밀어도 인정.
- 1인당 2번 시도, 쓰러뜨린 컵 개수 = 점수.
- 컵 안에 사탕을 넣어 두면 난리 납니다(좋은 의미로).

## 5. 게임 3 - 링 통과 슬라럼 (10분)

- 훌라후프를 의자 두 개에 걸쳐 문처럼 세웁니다. 링이 없으면 책상 두 개 사이를 "게이트"로 씁니다.
- 코스: 출발선 → 링 통과 → 반환점 돌기 → 착륙장 착륙.
- **시간 측정.** 기록을 칠판에 바로 적습니다. 순위가 보이면 아이들이 다시 하겠다고 합니다.
- 링 건드리면 +3초 벌점.

## 6. 남는 시간용 보너스 게임

- **드론 택배**: 포스트잇을 드론 위에 올려 목적지까지 떨어뜨리지 않고 배달.
- **2인 협동 비행**: 한 명은 눈 가리고 조종, 다른 한 명이 말로만 안내. 가장 웃긴 게임입니다.
- **코딩드론이 있다면**: 블록 코딩으로 "앞 1m → 오른쪽 90도 → 반복 4번" 정사각형 비행. 정사각형이 안 닫히는 이유를 같이 찾아보면 그대로 각도 수업이 됩니다.

## 7. 수학 연결 (수학학원용 마무리, 7분)

드론만 날리고 끝내면 아깝습니다. 기록표 숫자로 바로 수학을 합니다.

- **평균**: 모둠원 착륙 점수의 평균 구하기.
- **속력**: 슬라럼 거리(약 6m) ÷ 걸린 시간 = 초속 몇 m인지 계산.
- **최댓값·최솟값·범위**: 우리 반 최고 기록과 최저 기록의 차이.
- **각도**: 정사각형 비행에서 90도를 85도로 주면 어떻게 어긋나는지 그림으로 설명.
- **확률 한 스푼**: 3번 던져 2번 성공 = 성공률 몇 %?

## 9. 드론이 고장났거나 못 날릴 때 (플랜 B)

- **종이 드론 대회**: A4 종이비행기를 접어 같은 착륙장 게임을 그대로 진행. 규칙이 똑같아서 바로 됩니다.
- **드론 시뮬레이터**: 무료 웹 시뮬레이터로 조종 연습만 해도 한 시간이 갑니다.
- **드론 진로 이야기**: 배달·농업 방제·측량·소방·촬영 드론 영상 보고 "내가 만들고 싶은 드론" 그리기.

## 10. 인원·공간별 조정표

| 상황 | 이렇게 바꾸세요 |
| --- | --- |
| 드론 1대, 학생 8명 | 2인 1조 - 한 명 조종, 한 명 기록. 라운드마다 역할 교대 |
| 공간이 좁다 | 슬라럼 빼고 착륙장 거리를 1m / 1.5m / 2m로 줄이기 |
| 저학년 | 호버링 3초 + 착륙장 게임만. 볼링은 착륙해서 밀기 허용 |
| 고학년 | 전 게임 시간 측정, 기록을 그래프로 그려 비교 |
| 배터리 부족 | 게임 2개만 하고 기록·계산 시간을 늘리기 |

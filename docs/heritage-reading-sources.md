# 고려·조선 역사신문 편집 기준과 출처

검토일: 2026-11-09

## 교육과정 연결 범위

초등 사회에서 유물과 기록으로 옛사람의 생활과 생각을 추론하는 학습을 바탕으로 구성했다. 고려는 불교·인쇄·공예와 생활을 연결하고, 조선은 세종 때의 과학 기술·농사 지원·백성을 돌보려는 정치와 생활을 연결했다. 조선 과학 유물은 시대의 생활을 이해하기 위한 확장 사례로 다룬다.

특정 출판사와 교과서 페이지는 제공되지 않아 해당 교과서 문장을 직접 대조했다고 표시하지 않는다. 모든 유물이 교육과정에 개별적으로 명시되어 있다고 주장하지 않는다. 교육과정과 교과서의 학습 주제, 공공기관의 역사적 근거, 수업을 위한 해석을 구별한다.

## 지면과 자료 원칙

- 웹 읽기 화면, 인쇄 PDF, AI 문제 생성 프롬프트는 동일한 JSON 본문을 사용한다.
- 유물별 약 900~980자의 6문단을 유지하고, A4 한 장에서 본문 약 2/3 분량을 확보한다. 인쇄 본문은 12.25~12.75pt, 한글 어절 단위로 줄을 나눈다.
- 큰 기사 제목, 부제, 교과 연계, 도입 기사, 사진과 설명, 소제목을 넣은 2단 본문, 근거별 출처로 구성한다. 과거에 실제 발행된 신문처럼 가짜 날짜·기자·인터뷰를 넣지 않는다.
- 공공기관 자료를 쉬운 말로 새로 서술한다. 사진은 기존의 실제 촬영 자료를 사용하고 촬영자·라이선스를 유지한다. 사진과 설명 자료가 다른 개체인 경우 이를 구별한다.
- 원본과 복원품, 사실과 추정, 유물 종류의 일반적 용도와 개별 유물의 확인된 용도를 구별한다.
- 국가유산포털 일부 상세 페이지는 본문 직접 열기가 제한되어 검색에 공개된 기관 해설과 박물관 자료를 대조했다.

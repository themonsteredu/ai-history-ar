# 삼국시대: 2·3차시 통합 수업 이후의 연결 기준

적용 범위는 삼국시대 4~10차시다. 이미 수업한 1~3차시와 조선시대 내용·인쇄물을 다시 만들지 않는다. 차시 번호는 유지한다. 다음 수업은 4차시다.

## 학습 기준

학생이 이미 판단한 AI 설명과 공식 자료의 근거를 끝까지 이어 사용한다. 교사가 고른 여섯 유산의 수를 나라의 힘이나 문화 수준으로 해석하지 않는다.

- 한 행 = 서로 다른 근거 문장 하나. 같은 출처의 다른 문장은 중복이 아니다.
- 공통 분류 = 시기·발견 / 재료·구조 / 모양·장면 / 사용·생활.
- 확인 상태 = 확인됨 / 판단 보류 / 추가 확인. 학생이 원문 또는 인쇄 자료를 읽고 판단한다.
- 연도는 근거 문장에서 제작·발견·등재의 의미를 명시한다. 의미가 다른 숫자를 연속적인 연도 그래프로 만들지 않는다.
- 그래프는 **우리가 살펴본 근거의 분류와 상태**를 센다. 역사적 분포나 인구를 추정하는 통계가 아니다.
- 8차시 유추는 그래프의 높이가 아니라 선택한 두 근거의 내용으로 뒷받침한다. 모든 모둠에 교류라는 결론을 강요하지 않는다.
- 자료실의 3개 카드는 같은 원문의 부분일 수 있다. 서로 다른 독립 출처 3곳으로 안내하지 않는다.

| 차시 | 가져올 것 | 수업 | 다음 차시로 넘길 것 |
|---|---|---|---|
| 4 | 지난 2·3차시 활동지 | 의심한 말·판단을 가져와 공식 자료의 근거 3~5개 선택 | 근거 표, 원본 CSV, 작업 파일 |
| 5 | 4차시 작업 파일 | 같은 표의 중복·분류·출처 점검 | 정제 CSV와 작업 파일 |
| 6 | 정제한 같은 CSV | CODAP에서 항목별 근거 수 그래프 제작 | PNG를 포함한 작업 파일 |
| 7 | 그래프가 포함된 파일 | 실제 개수와 조사 범위의 한계 설명 | 관찰점·한계를 포함한 파일 |
| 8 | 확인된 근거와 그래프 | 근거 두 개로 가능한 과거 모습과 한계 설명 | 두 근거·설명·한계를 담은 파일 |
| 9 | 8차시 결과 | 핵심 근거·사진 표현·관람객 활동 선택, 전시 시험 | 실제로 열리는 최종 전시 파일 |
| 10 | 9차시 최종 파일과 2·3차시 활동지 | 해설·관람 교대 및 처음 판단과 현재 설명 비교 | 전시·관찰·돌아보기 기록 |

## 학생 작업 파일

이 프로젝트는 기존의 파일 기반 수업을 사용한다. JSON 작업 파일이 학생 산출물이며 근거·출처·PNG·해석·유추·전시 선택을 한 번에 담는다. CSV는 CODAP/Sheets용 표, PNG는 그래프다. 웹앱의 브라우저 저장은 임시 초안으로만 사용한다. 매 차시 파일을 학급 폴더에 보관하고, 다른 기기에서는 그 파일을 직접 불러온다. 서버에 학생 정보를 수집하거나 새로운 운영 DB를 연결하지 않는다.

모둠 번호와 유산 번호는 독립적이다. 이미 수업한 실제 배정대로 고른다. 유산을 바꾸거나 다른 파일을 열 때 현재 작업의 보관 여부를 확인한다.

표를 수정하면 정제 확인·그래프·이후 해석 및 전시 점검이 무효화된다. 이전 PNG는 비교를 위해 남지만 최신 표와 맞는 그래프를 다시 가져오기 전에는 다음 완료 단계로 넘어갈 수 없다. 서로 다른 확인된 근거 두 개가 없는 유추는 완료하지 않는다.

## 외부 도구

Google Sheets는 같은 표를 살펴보는 선택 실습이다. 최종 표는 웹앱의 근거 표에 맞춘 뒤 CSV로 받는다. CODAP은 그래프 제작에 사용한다. 빈 도구나 예비 CSV를 학생의 실제 작업으로 자동 연결하지 않는다. 교사 설정의 CODAP 수업 링크를 사용한다. 도구가 꺼졌거나 주소가 없으면 교사가 대안을 안내한다.

교사 설정에서 만든 **학생 기기용 수업 링크**에는 검증된 학생 실행·제출·결과 주소만 들어가며 교사용 원본 주소는 제외된다. 학생 기기에서 해당 링크를 열어 설정을 받는다. 교사가 설정을 바꾸면 새 링크를 전달한다. 임의 도메인, HTTP, URL 내 자격 증명은 허용하지 않는다.

예비 CSV는 교사 연습용으로만 유지한다. 학생 활동은 자신의 4차시 파일부터 시작한다. 원래 계획의 미래 예측·Desmos·RAWGraphs는 이 후속 수업의 필수 활동이 아니다.

## 실제 AR·전시 범위

학생의 그래프·핵심 근거·유추·한계를 전시 화면에 넣고, 사진 표시/확대와 특징 찾기/근거 고르기를 실제로 실행한다. 카드 인식 후 정보에도 해당 모둠의 근거와 한계가 나타난다. 유산 사진과 고정 인식 표적을 사용하며 새 3D 모델·회전·영상·음성 제작을 약속하지 않는다. 기획서 체크만으로 완료되지 않으며 전시를 열어 점검해야 한다.

카메라 없는 전시도 같은 그래프·사진·해설·활동을 제공한다. 작품 파일을 다른 기기에서 열어 보는 절차는 9차시 운영에 포함한다. 실제 기기 카메라 인식은 교사가 수업 전에 확인한다.

## 10차시 운영 40분

준비 5분 → A팀 해설/B팀 관람 12분 → 교대 2분 → B팀 해설/A팀 관람 12분 → 정리 3분 → 돌아보기 6분. 관람팀은 각 4분씩 다른 부스 세 곳을 방문한다. 1차시 첫 생각 카드가 없으면 이미 사용한 2·3차시 활동지로 돌아본다.

## 유지보수

- 차시 원본은 `scripts/update_continuity_content.py`의 LESSONS. 실행하면 `lessons.ts`의 4~10차시와 `continuity-guide.json`이 같이 갱신된다.
- 웹 PPT는 `continuitySlides.ts`에서 같은 안내를 사용하고 기존의 역사 근거 슬라이드를 함께 유지한다.
- `python scripts/generate_continuity_printables.py`는 삼국시대 4~10차시의 학생 1쪽·교사 2쪽·판단 기준 1쪽만 재생성한다. 1~3차시와 조선시대를 삭제하거나 덮어쓰는 기존 전체 생성 명령을 이번 후속 수정에 사용하지 않는다.
- 학생 작업 검증은 `project.test.ts`, 수업 링크 전송 검증은 `externalToolSettings.test.ts`에서 수행한다.

## 운영본 통합 (2026-09-05)

- 운영 중인 2·3차시 통합 수업과 Career Log 최신 수정본을 기준으로 4~10차시를 연결했다. 화면의 차시 순서 `[1, 2, 4, 5, 6, 7, 8, 9, 10]`을 유지한다.
- Hub 참여 정보는 후속 차시 이동에도 유지하고 모둠 임시 작업은 해당 참여자별로 분리한다. 4~10차시 파일을 Career Log에 자동 전송하지 않는다.
- 이미 사용한 1~3차시 및 조선시대 PDF/PPT 53개를 원본과 비교해 보존했다. 배포 때 2차시 생성 작업이 다시 실행되지 않도록 해당 생성 워크플로를 수동 실행으로 전환했다.
- 4차시의 이전 일곱 항목 활동지와 PPT 다운로드는 새 근거 표와 혼동되지 않도록 후속 과정에서 제거했다. 4~10차시 수업 PPT는 기존처럼 웹 화면에서 연다.
- 미리보기 배포를 생성하지 않도록 Git 자동 배포는 끄고, 검증한 커밋을 명시적으로 Production 대상으로 배포한다.

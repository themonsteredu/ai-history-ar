# 삼국시대 데이터·AI·AR 외부 도구 수업 허브 구현 계획

> **이전 설계 기록.** 2·3차시 수업을 마친 학급의 현재 4~10차시에는 [후속 연결 기준](THREE_KINGDOMS_CONTINUITY.md)을 적용한다. 아래의 데이터 설계 2차시·미래 예측 9차시 및 구현 완료 표시는 현재 운영 기준이 아니다.

> 구현 상태: 1~6단계 완료. Google Forms·Sheets의 실제 학급용 주소는 교사가 PIN 설정 화면에서 연결한다. CODAP·Desmos는 기본 실행 주소와 예비 CSV가 연결되어 있다.

## 1. 구현 목표

초등학교 5학년 삼국시대 10차시 수업을 `역사 자료 수집 → 데이터 정리 → 시각화 → 해석 → 과거 유추 → 미래 예측 → AR 전시`의 흐름으로 재구성한다.

웹앱 안에서 표 계산기, 설문, 시각화 도구를 다시 만들지 않는다. 웹앱은 다음 기능에 집중한다.

- 교사는 PIN 3035로 잠긴 설정 화면에서 차시별 외부 도구 주소와 사용 상태를 관리한다.
- 학생 화면에는 `수업 PPT`와 `웹앱 활동`만 노출한다.
- 웹앱 활동은 차시 목표, 짧은 실행 안내, 외부 도구 실행 버튼, 결과 제출 방법만 보여 준다.
- 임베드가 허용되는 도구는 수업 화면 안에서 열고, 편집 화면이나 임베드 제한이 있는 도구는 새 탭으로 연다.
- 작업 결과는 링크·CSV·PNG 가운데 하나로 회수하고, 같은 내용을 웹앱에 다시 입력시키지 않는다.

## 2. 우선 구현 범위

- 1차 적용: 삼국시대 10차시
- 유지: 조선시대 과정과 현재 AR 기능
- 개편: 삼국시대 `lessons.ts`, 차시별 PPT 내용, 웹앱 활동, 교사용 도구 설정
- 비공개 유지: 지도안·학생활동지·활동카드·답안 다운로드
- 공개 유지: 학생용 수업 PPT와 웹앱 활동

## 3. 차시별 외부 도구 구성

| 차시 | 역사·데이터 활동 | 주 도구 | 웹앱 실행 방식 | 학생 결과 |
|---|---|---|---|---|
| 1 | 유산을 관찰하고 어떤 데이터를 모아야 하는지 문제 찾기 | 내장 PPT·유산 이미지 | 웹앱 내부 | 모둠별 데이터 질문 1개 |
| 2 | 공통 데이터 항목과 항목 사이의 관계 정하기 | Google Sheets 읽기용 예시 | 읽기 전용 임베드 | 모둠 데이터 설계표 |
| 3 | 믿을 수 있는 출처와 수집 방법 정하기 | Google Forms | 폼 임베드 | 수집 연습 응답 |
| 4 | 유산별 자료 12~20건 수집하기 | Google Forms·Sheets | 폼 임베드 + 시트 새 탭 | 모둠 원자료 |
| 5 | 중복·빈칸·표기 차이를 고쳐 데이터 전처리하기 | Google Sheets | 편집 시트 새 탭 | 정리된 CSV 또는 시트 링크 |
| 6 | 연도·지역·종류별 데이터를 시각화하기 | CODAP | 임베드 우선 | 그래프 PNG 또는 공유 링크 |
| 7 | 그래프가 말하는 점과 말하지 못하는 점 해석하기 | CODAP | 임베드 우선 | 모둠 해석 카드·발표 자료 |
| 8 | 여러 자료의 관계로 과거의 생활·교류 유추하기 | CODAP, 선택 RAWGraphs | CODAP 임베드, RAWGraphs 새 탭 | 근거 2개를 포함한 과거 유추 |
| 9 | 보존·관람·디지털 이용의 미래 경향 예측하기 | Desmos | 교사 템플릿 새 탭 | 3가지 시나리오와 한계 |
| 10 | 데이터 근거와 AR 해설을 연결해 박물관 열기 | 내장 AR + 결과 링크 | 웹앱 내부 AR, 외부 결과 열기 | 모둠별 AR 데이터 전시 |

선택 도구인 TimelineJS와 Google My Maps는 각각 정확한 연도가 있는 사건·발견·지정 자료와 위치 자료가 충분한 모둠에만 제시한다. 모든 모둠에 동일한 도구를 강요하지 않는다.

## 4. 도구별 적용 원칙

| 도구 | 권장 용도 | 기본 방식 | 유의점 |
|---|---|---|---|
| Google Forms | 공통 양식으로 역사 자료 수집 | 임베드 | 교사가 양식을 소유하고 모둠 번호만 받는다. |
| Google Sheets | 원자료 확인·전처리·간단한 그래프 | 읽기용 임베드, 편집은 새 탭 | 학교 계정과 공유 권한을 수업 전에 확인한다. |
| CODAP | 범주·연도·수량 관계를 끌어 놓아 시각화 | 임베드 | 공유 문서가 열리지 않으면 새 탭 버튼을 함께 제공한다. |
| RAWGraphs | 관계·흐름 그래프의 선택 확장 활동 | 새 탭 | 결과를 PNG로 내려받아 제출한다. |
| TimelineJS | 발견·발굴·지정처럼 정확한 연도 자료의 시간 흐름 | 임베드 | 공개 시트에는 이름·이메일 등 개인정보를 넣지 않는다. |
| Google My Maps | 출토지·소장처·고분군 위치 비교 | 공개 지도 임베드 | 편집이 필요하면 교사 계정에서 준비한다. |
| Desmos | 관람객·보존 상태 같은 연도별 수치의 추세선과 시나리오 | 새 탭 | 역사적 사실을 예측하지 않고 가정과 한계를 함께 기록한다. |

## 5. 화면 구조

### 학생 화면

현재 `/three-kingdoms/lesson/:lessonId?view=activity` 경로를 유지하고 다음 순서로 단순화한다.

1. 오늘의 한 문장 목표
2. 사용할 도구와 예상 소요 시간
3. `화면 안에서 시작` 또는 `새 탭에서 시작` 버튼
4. 세 단계 실행 안내
5. 제출할 결과 형식과 파일명 예시
6. `결과 제출` 버튼 또는 완료 체크
7. 연결 실패 시 대체 자료 버튼

학생 화면에는 교사용 설정 URL, 정답, 지도안, 활동지 다운로드를 노출하지 않는다.

### 교사 설정 화면

PIN 3035 뒤에 `/teacher/three-kingdoms/tools`를 추가한다.

- 10개 차시별 도구 사용 여부
- 학생 실행 URL, 임베드 URL, 교사용 원본 URL
- 결과 제출 폼 URL
- 도구별 `준비 완료 / 확인 필요` 상태
- 새 탭·임베드 방식 선택
- 공개 전 개인정보 점검표
- 설정 JSON 내보내기·불러오기

GitHub Pages는 정적 사이트이므로 1차 구현에서는 설정을 브라우저 저장소에 보관한다. 학급용 공통 설정은 검토가 끝난 URL만 코드의 기본 설정 파일에 반영한다. 별도 서버와 학생 계정은 만들지 않는다.

## 6. 코드 설계

### 새 파일

- `src/types/externalTools.ts`: 도구, 실행 방식, 결과 형식 타입
- `src/content/three-kingdoms/externalTools.ts`: 10차시 기본 도구 구성
- `src/components/ExternalToolActivity.tsx`: 학생용 외부 도구 실행 패널
- `src/components/ExternalToolFrame.tsx`: iframe 로딩·새 탭 전환·오류 대체
- `src/pages/TeacherToolSettingsPage.tsx`: PIN 내부 교사용 설정
- `src/settings/externalToolSettings.ts`: 저장·불러오기·검증·기본값 병합

### 핵심 데이터 형태

```ts
type ToolLaunchMode = "embed" | "new-tab" | "internal";
type ToolResultKind = "link" | "csv" | "png" | "none";

interface LessonExternalTool {
  lessonId: number;
  toolId: string;
  toolName: string;
  purpose: string;
  launchMode: ToolLaunchMode;
  studentUrl?: string;
  embedUrl?: string;
  teacherSourceUrl?: string;
  resultKind: ToolResultKind;
  resultGuide: string;
  fallbackPath?: string;
  allowedDomains: readonly string[];
}
```

`LessonWebActivity.tsx`의 차시별 조건문은 이 설정 데이터를 읽는 방식으로 바꾼다. AR처럼 웹앱만이 할 수 있는 기능은 `internal`, 외부 편집이 필요한 활동은 `new-tab`, 공식적으로 임베드 가능한 활동은 `embed`로 처리한다.

## 7. 결과 회수 방식

외부 도구에서 만든 내용을 웹앱에 다시 작성하게 하지 않는다.

- Google Forms·Sheets: 모둠별 공유 링크
- CODAP·Desmos: 공유 링크 또는 화면 캡처 PNG
- RAWGraphs: 내려받은 PNG
- 전처리 결과: CSV
- 최종 제출: 교사 소유 Google Form 한 곳에서 모둠 번호, 차시, 링크 또는 파일만 수집
- AR 전시: 교사가 확인한 모둠별 결과 링크를 AR 해설 카드와 연결

1차 구현에서는 학생 개인정보와 파일을 웹앱 서버에 저장하지 않는다. 장기 저장은 학교가 관리하는 Google Workspace 안에서 처리한다.

## 8. 데이터 기준

모든 모둠이 같은 항목 이름을 사용해야 모둠 간 비교가 가능하다.

필수 공통 항목:

- 모둠 코드
- 유산 이름
- 국가·정치체
- 자료 종류
- 시기 또는 연도
- 발견·출토 지역
- 현재 소장·관리 기관
- 확인된 사실
- 해석 또는 유추
- 자료 상태: 확인됨 / 주의 / 판단 보류
- 출처 기관
- 출처 URL
- 확인 날짜

연도가 정확하지 않은 제작 시기는 `6세기`, `삼국시대 후기`처럼 범위로 보존한다. 정확한 연도 그래프에는 발견 연도, 발굴 연도, 지정 연도, 관람 통계처럼 실제 연도가 있는 자료를 사용한다.

## 9. 실패 대비

- iframe이 차단되면 같은 카드에서 `새 탭으로 열기`를 즉시 제공한다.
- 외부 서비스에 접속할 수 없으면 차시별 예비 CSV·PNG·인쇄 활동카드로 진행한다.
- 링크가 비어 있거나 허용 도메인이 아니면 학생 화면에는 실행 버튼을 숨기고 교사 화면에만 오류를 표시한다.
- 팝업 차단, 학교 계정 권한, 모바일 화면, 느린 네트워크를 수업 전 점검한다.
- 외부 서비스 로고나 화면이 바뀌어도 수업 목표와 결과 형식은 유지되도록 안내문을 도구 이름과 분리한다.

## 10. 구현 단계

### 1단계 · 수업 데이터 정합성

- 새 10차시 지도안에 맞춰 삼국시대 `lessons.ts`를 수정한다.
- 차시 제목, 목표, 활동, 산출물, 평가가 지도안과 일치하는지 테스트한다.
- 기존 학생·교사용 PDF는 새 내용으로 다시 생성한다.

완료 기준: 웹 화면, PPT, 활동지, 교사용 답안의 차시 이름과 산출물이 모두 일치한다.

### 2단계 · 외부 도구 설정 기반

- 외부 도구 타입과 10차시 기본 설정을 추가한다.
- URL 허용 도메인, 빈 URL, 실행 방식 검증을 구현한다.
- 현재 하드코딩된 웹 활동을 설정 기반 라우팅으로 교체한다.

완료 기준: 각 차시가 설정값만으로 내부·임베드·새 탭 활동 중 하나를 정확히 연다.

### 3단계 · 학생용 실행 허브

- 학생 활동 화면을 한 목표, 한 실행 버튼, 세 단계 안내 중심으로 단순화한다.
- 임베드 로딩 상태, 새 탭 대체, 결과 형식, 예비 자료를 구현한다.
- 휴대폰과 교실 프로젝터에서 글자 크기와 터치 영역을 확인한다.

완료 기준: 초등학교 5학년 학생이 교사 설명 후 30초 안에 활동을 시작할 수 있다.

### 4단계 · 교사용 설정

- PIN 영역에 외부 도구 설정 화면을 추가한다.
- URL 입력, 실행 미리보기, 준비 상태, 설정 내보내기·불러오기를 구현한다.
- 학생 화면과 교사 원본 URL을 분리한다.

완료 기준: 교사가 코드를 수정하지 않고 각 차시의 수업용 링크를 바꿀 수 있다.

### 5단계 · 결과 제출과 AR 연결

- 모둠 결과 제출 폼을 차시별 버튼으로 연결한다.
- 10차시 AR 전시에 모둠별 그래프·해석·예측 결과 링크를 연결한다.
- 링크가 없는 모둠은 교사 검토 전 상태로 표시한다.

완료 기준: 한 모둠의 수집 자료, 그래프, 해석, 예측, AR 해설을 한 흐름으로 열 수 있다.

### 6단계 · 검증과 배포

- 단위 테스트: 설정 병합, URL 검증, 차시 매핑, 저장소 복구
- 화면 테스트: 데스크톱 1440px, 태블릿 768px, 모바일 390px
- 수업 테스트: 로그인 필요 여부, 팝업, iframe 차단, 결과 제출, 예비 자료
- 접근성: 키보드 이동, 명확한 버튼 이름, 로딩·오류 안내
- `pnpm test`, `pnpm build`, 주요 경로 브라우저 검증 후 GitHub Pages 배포

완료 기준: 10개 차시 모든 도구가 정상 실행되거나 한 번의 클릭으로 대체 경로를 제공한다.

## 11. 필요한 교사 준비 자료

실제 URL을 연결하기 전에 다음 원본을 교사 계정에서 준비한다.

- Google Forms: 자료 수집 폼, 최종 결과 제출 폼
- Google Sheets: 공통 데이터 표, 6개 모둠 편집 탭
- CODAP: 공통 열 이름이 들어간 시작 문서
- Desmos: 연도·수치 표와 추세선 예시가 든 교사 템플릿
- 선택 자료: TimelineJS 공개 시트, My Maps 공개 지도

이 원본을 복제해 수업용 공유 링크를 만든 뒤 교사용 설정 화면에 넣는다. 계정이 필요한 설정 작업은 교사가 하고 학생은 교사가 제공한 링크만 사용한다.

## 12. 구현 결과

- 삼국시대 10차시의 웹 화면·PPT·활동지·교사용 답안을 같은 차시 구조로 개편했다.
- 학생 활동은 한 목표, 실행 버튼, 세 단계 안내, 결과 형식, 완료 표시로 단순화했다.
- 교사는 `/teacher/three-kingdoms/tools`에서 차시별 주소와 실행 방식을 바꾸고 설정을 JSON으로 옮길 수 있다.
- URL 허용 도메인과 필수 주소를 저장 전에 검사하며, 학생에게는 검증을 통과한 실행 주소만 노출한다.
- 1·10차시는 내부 활동, 2~5차시는 교사 소유 Google 자료, 6~8차시는 CODAP, 9차시는 Desmos를 사용한다.
- 모바일 390px과 데스크톱 1440px, 슬라이드 이미지·넘침, PIN 잠금, PDF·ZIP·CSV 다운로드를 자동 검증한다.

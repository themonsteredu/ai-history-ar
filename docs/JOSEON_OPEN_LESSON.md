# 조선시대 공개수업 · 세종 때 과학 유물 AR 카드

- 학생 화면: `/joseon/open-class?code=수업코드`
- 선생님 화면: `/teacher/joseon/open-class` (교사 PIN 화면 안)
- 유물 6종: 측우기 · 자격루 · 간의 · 앙부일구 · 혼천의 · 농사직설 — 실물 사진을 참고한 3D 재현 모형(녹음 없음)

## 사전 준비

학생은 유물을 고르고 설명 점 2~6개를 담은 AR 카드를 미리 제작합니다. 사전 준비 메뉴는 당일 활동 탭과 분리되어 있습니다. 기존 카드와 이전 검증 기록은 보존합니다.

## 공개수업 당일 (40분)

1. 안내 3분.
2. AR 카드 발표 10분: 특징·쓰임·백성 생활에 준 도움·확인한 출처를 소개하고 여섯 유물의 발표를 핵심어로 기록합니다.
3. AI 문제 만들고 검증 15분: 역할·상황·답하는 방법을 학생이 작성합니다. 제미나이에 질문을 붙여 넣어 OX 초안 2개와 AI 정답·해설을 받고, 교과서·참고 자료에서 사실을 확인합니다. 자료 이름·쪽수/주소, 확인한 정답, 채택·수정·제외, 이유, 최종 해설을 기록합니다. AI를 다시 물어보는 것으로 검증을 대신하지 않습니다.
4. 퀴즈 발표 9분: 채택·수정하고 근거를 모두 작성한 문제만 출제합니다. 친구들이 답한 뒤 정답·근거를 공개합니다. 제외한 문항은 발표 문제에서 빠지며 검증 기록에는 남습니다.
5. 정리 3분: 오늘 알게 된 점과 AI 정보를 확인해야 하는 까닭을 기록합니다.

활동지는 `/downloads/joseon/open-class/student-worksheet.pdf`에 있습니다. 원본 AI-L.E.A.P. 로고와 학습목표는 첫 페이지에만 표시하며, 2페이지에 걸쳐 작성 공간을 확보했습니다.

## 선생님 화면

반 목록·입장 QR·AR 인식 카드 인쇄는 유지합니다. 모둠 현황에서는 자기 모둠의 AI 문제 검증과 완료 수를 확인합니다. 발표 화면은 처음에 정답을 숨깁니다. 이전 방식의 다른 모둠 검증 기록도 볼 수 있으며, 교사 추가 문항은 이전 수업용으로 접어 두고 이번 수업의 2문항에는 합치지 않습니다.

## 자기 모둠 검증 저장

`verify`의 `모둠:모둠` 키와 `mode: self`를 사용합니다. AI 초안 두 문제는 `selfQuestions`, 발표·듣기·성찰은 `notes`, 자료 근거는 각 검증 행의 `why`에 저장합니다. 이전 카드 문제나 다른 모둠 검증 기록을 덮어쓰지 않습니다. AI 초안을 수정하면 해당 문항의 검증을 다시 작성합니다. SQL 업데이트는 `db/history-ar-open-self-inquiry.sql`, Edge 번들은 `node scripts/build-open-lesson.mjs`로 생성합니다.

## 수업 준비하기 (학교 인터넷이 느릴 때)

- **언제 누르나요?** 수업 당일, 인터넷이 잘 될 때 모둠 태블릿마다 학생 화면(학생 QR로 여는 `https://ai-history-ar.vercel.app/joseon/open-class`)에서 `수업 준비하기`를 한 번 누릅니다. `준비 완료 · 오후 2:05`가 나오면 끝입니다(태블릿마다 약 15MB, 보통 1분 안쪽). 선생님 기기는 선생님 화면의 같은 버튼으로 따로 준비합니다.
- **준비하면 인터넷이 느리거나 잠깐 끊겨도 되는 것**: 수업 화면 열기(3.5초 안에 답이 없으면 태블릿에 담아 둔 화면을 엽니다), 유물 6종의 3D 모형과 사진 표면, 인쇄 카드를 비추는 AR 카메라. 쓰던 카드 내용은 태블릿에 남습니다.
- **그래도 인터넷이 꼭 있어야 하는 것**: 처음 `수업 들어가기`, 반에 저장하기, 다른 모둠 카드 보기, 선생님 화면의 모둠 현황과 문제 저장, 제미나이.
- **다시 눌러야 할 때**: 사이트가 새로 바뀌면 버튼 옆에 “사이트가 새로 바뀌었어요. 수업 준비하기를 한 번 더 눌러 주세요.”가 나옵니다. 그때까지는 태블릿에 담아 둔 지난 버전이 인터넷 없이 열립니다. “화면을 새로 고친 뒤 다시 눌러 주세요”가 나오면 화면을 새로 고친 다음 누릅니다. 아이패드(사파리)는 7일 넘게 열지 않은 사이트의 파일을 지울 수 있으니 수업 당일에 누르세요. 다른 주소(미리보기 주소 등)에서 누르면 학생 QR 주소에는 적용되지 않습니다.
- 동작 방식: `public/open-lesson-sw.js`(서비스 워커)를 버튼을 누른 화면의 주소(`/joseon/open-class` 또는 `/teacher/joseon/open-class`)에만 등록하므로 사이트의 다른 화면은 영향을 받지 않습니다. 화면 주소는 인터넷 먼저(3.5초) → 담아 둔 화면(새 버전의 화면은 수업 준비하기가 그 버전의 파일을 모두 담은 뒤에만 담습니다), `/assets/` 파일은 담아 둔 것 먼저, 사진·`.mind`·글꼴은 담아 둔 것을 쓰면서 뒤에서 새 버전을 확인합니다. `/api/`는 언제나 인터넷으로만 보냅니다. 버튼을 다시 누르면 지난 버전 파일은 지웁니다. `vercel.json`이 워커 파일을 `no-cache`로 보내 새 배포 때 바로 바뀝니다. 기능을 끄려면 activate에서 `open-lesson-*` 캐시를 지우고 `self.registration.unregister()`를 부르는 워커를 배포합니다.

## 저장 구조

- 학생 입장은 기존 `/api/ar-studio/join`(수업코드·모둠 입장)을 그대로 씁니다.
- 카드·검증 기록·선생님 문제는 `/api/open-lesson` → Supabase Edge Function `history-ar-open` → `public.history_ar_open_dispatch` → `history_ar.open_items` 에 저장됩니다. 기존 삼국시대 작품·답안 표는 바꾸지 않습니다.
- 모둠은 자기 카드와 자기 검증 기록만 저장할 수 있고, 같은 항목을 두 태블릿이 동시에 저장하면 버전 번호로 겹침을 알려 줍니다. 쓴 내용은 태블릿에도 임시 보관됩니다.
- 선생님 문제 저장은 Edge 함수가 교사 PIN(`OPEN_LESSON_TEACHER_PIN`, 기본값은 사이트 PIN)을 확인합니다.
- 함수 코드 다시 만들기: `node scripts/build-open-lesson.mjs` → `supabase/functions/history-ar-open/` 배포. DB 정의는 `db/history-ar-open-lesson.sql`.

## 3D 모형과 실물 사진

- 모형 코드: `src/lib/ar/joseon/` — `toolkit.ts`(공통 도구), 유물별 파일 6개, `catalog.ts`(사진·사진 영역 설정).
- 모형은 실측·스캔 원본이 아닌 **사진 참고 3D 재현**입니다. 보이지 않는 부분은 추정했습니다.
- 사진 입히기: 각 모형은 부분마다 사진 영역 이름(`region`)을 갖습니다. `catalog.ts`의 `photo.views`에 영역별로 사진을 찍은 높이(`elevation`, 도)·방향(`azimuth`)·사진 속 위치(`frame` = 왼쪽, 위, 오른쪽, 아래 0~1)를 적으면 그 방향에서 사진이 모형에 투영됩니다.
- 사진이 없는 유물은 모양과 재질 색만 보이며, 화면에 “실물 사진 준비 중”이라고 표시합니다. 사진을 불러오지 못하면 그 사실을 알립니다.
- 사진 파일: `public/images/heritage/joseon-science/`(위키미디어 공용 원본을 1280px로 축소). 출처·저작자·이용 조건·변경 내용·SHA-256은 `src/lib/ar/joseon/photos.json`에 있고, 사진을 모형에 얹는 방향(`photoViews`)은 유물별 모형 파일에 있습니다. 앙부일구만 예외로, 인쇄 카드와 `.mind`는 원본 `public/images/heritage/joseon/angbuilgu.jpg`를 쓰고 3D 모형 표면은 같은 사진을 줄인 `joseon-science/angbuilgu.jpg`(photos.json의 `texture`)를 씁니다.
- CC BY-SA 사진을 입힌 3D 표면과 인쇄 카드는 같은 CC BY-SA 조건으로 공유합니다. 화면과 인쇄 카드에 사진 출처를 표시합니다.
- AR 인식 카드: `node scripts/compile_joseon_science_targets.mjs`가 사진 6장을 `public/ar/joseon-science-targets.mind`로 만듭니다(@napi-rs/canvas 필요). 사진을 바꾸면 다시 만들어야 하고, 인쇄 카드도 새 사진으로 다시 인쇄해야 합니다.
- 인쇄용 카드는 실물 사진(있을 때)과 설명 목록, 입체 모형을 여는 QR로 구성됩니다.

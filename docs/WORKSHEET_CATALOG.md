# 교사용 활동지 다운로드 카탈로그

## 1. 다운로드 센터 공통 기능

교사용 화면에서 시대와 차시를 선택하면 아래 기능을 제공한다.

- 활동지 화면 미리보기
- 낱장 PDF 다운로드
- 해당 차시 자료 전체 PDF 다운로드
- 해당 차시 자료 ZIP 다운로드
- 시대별 10차시 전체 ZIP 다운로드
- 흑백 인쇄용 모드
- 컬러 인쇄용 모드
- 학생용 / 교사용 정답·운영안 구분
- A4 세로 기본, 7차시 카드 원화는 A6 규격
- 파일명 규칙: `{era}_lesson-{nn}_{document-id}_v{version}.pdf`

지도안에는 차시별 과정 산출물 9종이 제시되어 있으나, 웹앱에서는 교사가 **모든 차시에서 바로 내려받을 수 있도록** 9차시 실전 테스트지와 10차시 공개수업 운영지를 추가해 시대별 10세트로 제공한다.

## 2. 삼국시대 10차시 활동지

| 2 | 오류 발견 기록지 | 유산별 질문 카드 6종, AI 답변 출력물 템플릿, 오류 유도 준비 체크 | A4 |

| 4 | 모둠별 조사 카드, 출처 기록표, `아직 모름` 기록칸 | 모둠별 인쇄 자료집 표지·목차 템플릿 | A4 |
| 5 | AR 체험 평가 메모, AR 기획서, 카드 스케치 | 구현 가능성 피드백표 | A4 |

| 8 | 30초 해설 대본지, 녹음·촬영 체크리스트 | 초상권 동의서, 재녹음 판정표 | A4 |

### 삼국시대 활동지 고유 요소

- 3차시 검증 체크리스트에는 `보류 - 아직 아무도 모르는 것은 모름으로 남긴다`를 포함한다.
- 4차시 조사 카드에 `학자들도 아직 모르는 점`을 독립 칸으로 둔다.
- 6차시 판별지에 `진짜 / 가짜 / 판단 보류` 3개 선택지를 지원한다.
- 7차시 유산별 주조색과 시각 구분 규칙을 카드 템플릿에 표시한다.
- 무령왕릉과 가야 고분군 카드가 비슷해지지 않도록 서로 다른 시각 소재 안내를 넣는다.

- 7차시 조선왕조실록과 난중일기의 카드 도상이 모두 책 표지처럼 보이지 않도록 별도 시각 소재 안내를 제공한다.

## 6. PDF·인쇄 품질 기준

- 웹 화면과 PDF 모두 S-Core Dream을 적용한다.
- PDF 생성 시 한글이 이미지로 뭉개지지 않도록 글꼴을 포함한 벡터 텍스트를 유지한다.
- 활동지에 잘린 글자, 겹침, 깨진 한글, 고정 높이로 인한 누락이 없어야 한다.
- A4 출력 기준 안전 여백 12mm 이상을 확보한다.
- 학생 작성 칸은 최소 9mm 높이를 확보한다.
- 흑백 인쇄 시에도 표 구분과 체크 영역이 사라지지 않도록 색상만으로 의미를 전달하지 않는다.
- 모든 PDF는 브라우저 미리보기와 실제 출력 렌더를 비교 검수한다.

## 7. 다운로드 버튼 구성

각 차시 교사용 화면의 우측 고정 패널에 아래 버튼을 제공한다.

1. `학생 활동지 PDF`
2. `교사용 자료 PDF`
3. `이번 차시 전체 받기`
4. `인쇄 미리보기`
5. `10차시 전체 ZIP`

7차시에는 `A6 카드 원화 다운로드`, 10차시에는 `스탬프북·부스표지 받기`를 별도 강조 버튼으로 추가한다.

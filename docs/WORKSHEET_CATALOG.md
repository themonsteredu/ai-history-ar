# 교사용 활동지 다운로드 카탈로그

> 삼국시대 4~10차시는 [현재 후속 연결 기준](THREE_KINGDOMS_CONTINUITY.md)을 우선 적용합니다. 조선시대 전 차시는 [현재 조선시대 운영 기준](JOSEON_CONTINUITY.md)을 적용합니다. 학생 활동지 경로는 같으며 조선시대는 A4 한 장·세 활동으로 갱신되었습니다. 아래의 조선시대 표 외 초기 사양은 현재 운영 기준과 충돌할 경우 적용하지 않습니다.

## 1. 다운로드 센터 공통 기능

교사용 화면에서 시대와 차시를 선택하면 아래 기능을 제공한다.

- 활동지 화면 미리보기
- 낱장 PDF 다운로드
- 해당 차시 자료 전체 PDF 다운로드
- 해당 차시 자료 ZIP 다운로드
- 시대별 10차시 전체 ZIP 다운로드
- 흑백 인쇄용 모드
- 컬러 인쇄용 모드
- 학생용 / 교사용 정답·운영안 구분
- A4 세로 기본, 7차시 카드 원화는 A6 규격
- 파일명 규칙: `{era}_lesson-{nn}_{document-id}_v{version}.pdf`

지도안에는 차시별 과정 산출물 9종이 제시되어 있으나, 웹앱에서는 교사가 **모든 차시에서 바로 내려받을 수 있도록** 9차시 실전 테스트지와 10차시 공개수업 운영지를 추가해 시대별 10세트로 제공한다.

## 2. 삼국시대 10차시 활동지

|---|---|---|---|

| 2 | 오류 발견 기록지 | 유산별 질문 카드 6종, AI 답변 출력물 템플릿, 오류 유도 준비 체크 | A4 |

| 4 | 모둠별 조사 카드, 출처 기록표, `아직 모름` 기록칸 | 모둠별 인쇄 자료집 표지·목차 템플릿 | A4 |

| 8 | 30초 해설 대본지, 녹음·촬영 체크리스트 | 초상권 동의서, 재녹음 판정표 | A4 |

### 삼국시대 활동지 고유 요소

- 3차시 검증 체크리스트에는 `보류 - 아직 아무도 모르는 것은 모름으로 남긴다`를 포함한다.
- 4차시 조사 카드에 `학자들도 아직 모르는 점`을 독립 칸으로 둔다.
- 6차시 판별지에 `진짜 / 가짜 / 판단 보류` 3개 선택지를 지원한다.
- 7차시 유산별 주조색과 시각 구분 규칙을 카드 템플릿에 표시한다.
- 무령왕릉과 가야 고분군 카드가 비슷해지지 않도록 서로 다른 시각 소재 안내를 넣는다.

## 3. 조선시대 10차시 활동지

각 차시는 A4 세로 한 장, 활동 세 개입니다. 2차시에는 모둠별 활동지 여섯 종 중 해당 유산 한 장을 사용합니다. 교사용 진행 안내와 확인 기준도 차시마다 한 장씩 제공합니다.

| 차시 | 수업 | 활동지 순서 |
|---|---|---|
| 1 | 우리 유산과 질문 정하기 | 사진에서 보이는 것 찾기 → 궁금한 것 고르기 → 우리 질문 말하기 |
| 2 | AI가 한 말 판단하기 | 내 판단 표시하기 → 의심한 문장 고르기 → 찾아볼 자료 정하기 |
| 3 | 자료에서 확인하고 고쳐 말하기 | 자료를 만든 곳 확인하기 → 읽은 자료와 비교하기 → 고친 말 한 문장 남기기 |
| 4 | 찾은 내용을 표로 정리하기 | 지난 활동 돌아보기 → 문장 세 개를 표에 담기 → 표 한 줄 설명하기 |
| 5 | 우리 표를 깔끔하게 고치기 | 우리 표 살펴보기 → 필요한 곳 고치기 → 문장 수 세고 저장하기 |
| 6 | 우리 표로 그래프 만들기 | 나누어 셀 것 고르기 → CODAP에서 그래프 만들기 → 개수 확인하고 저장하기 |
| 7 | 그래프를 보고 말하기 | 개수 읽기 → 알 수 없는 것 고르기 → 친구에게 설명하기 |
| 8 | 자료로 옛날 모습 생각하기 | 문장 두 개 고르기 → 우리 생각 한 문장 쓰기 → 아직 모르는 것 남기기 |
| 9 | 우리 목소리로 안내하는 AR 전시 | 설명할 곳 두 군데 고르기 → 녹음하고 문제 만들기 → 친구 화면에서 확인하기 |
| 10 | 우리 반 유산 박물관 열기 | 우리 역할 정하기 → 다른 전시 세 곳 보기 → 달라진 생각 말하기 |

학생 전체 묶음은 15쪽, 2·3차시 다운로드 PPTX는 24장입니다. 1~10차시 교실 PPT는 수업 화면에서 열며, 6차시는 CODAP 실제 도움말 화면 7단계를 포함합니다. 9·10차시 AR 카드 6종은 별도 A4 PDF로 받습니다. 전체 ZIP에는 중복 사진을 줄이기 위해 카드 6쪽 묶음을 한 번만 넣습니다.

2차시 ○×△?는 처음 판단이며 3차시에 자료를 읽고 다시 판단합니다. 출처 번호는 `1 국가유산청 / 2 국립박물관 / 3 국사편찬위원회 / 4 기타`입니다. 이 번호는 신뢰도 순위가 아닙니다. 4차시부터 표·그래프·확인한 문장·녹음은 같은 모둠 작업 파일로 이어집니다.

## 6. PDF·인쇄 품질 기준

- 웹 화면과 PDF 모두 S-Core Dream을 적용한다.
- PDF 생성 시 한글이 이미지로 뭉개지지 않도록 글꼴을 포함한 벡터 텍스트를 유지한다.
- 활동지에 잘린 글자, 겹침, 깨진 한글, 고정 높이로 인한 누락이 없어야 한다.
- A4 출력 기준 안전 여백 12mm 이상을 확보한다.
- 학생 작성 칸은 최소 9mm 높이를 확보한다.
- 흑백 인쇄 시에도 표 구분과 체크 영역이 사라지지 않도록 색상만으로 의미를 전달하지 않는다.
- 모든 PDF는 브라우저 미리보기와 실제 출력 렌더를 비교 검수한다.

## 7. 다운로드 버튼 구성

각 차시 교사용 화면의 우측 고정 패널에 아래 버튼을 제공한다.

1. `학생 활동지 PDF`
2. `교사용 자료 PDF`
3. `이번 차시 전체 받기`
4. `인쇄 미리보기`
5. `10차시 전체 ZIP`

7차시에는 `A6 카드 원화 다운로드`, 10차시에는 `스탬프북·부스표지 받기`를 별도 강조 버튼으로 추가한다.

# 드론 빙고 - 바닥 점령 빙고 게임 (50분)

바닥에 빙고판을 깔고, **드론이 착륙한 칸을 팀 색으로 점령**하는 게임입니다.
한 줄을 먼저 완성한 팀이 승리. 착륙 실력 + 어디를 먼저 먹을지 머리싸움이 같이 들어갑니다.

## 준비물

- A4 용지 16장 (빙고판 칸)
- 매직 (칸에 숫자 쓰기)
- 마스킹테이프 (바닥 고정)
- 팀 색 표시물: 색종이 또는 포스트잇 2~4색, 팀당 8장씩
- 초시계 (휴대폰), 칠판 또는 큰 종이 (점수판)

## 빙고판 깔기 (10분, 학생과 함께)

1. A4 16장에 숫자를 하나씩 크게 씁니다. **1~16을 섞어서** 쓰세요.
2. 바닥에 **4 x 4**로 깝니다. 칸 사이를 **10cm씩 띄우면** 판정이 편합니다.
3. 테이프로 네 귀퉁이를 고정합니다. 전체 크기는 약 1.5m x 2m.
4. 출발선은 판에서 1.5m 떨어진 곳에 테이프로 그립니다.

판 예시 (이대로 쓰셔도 됩니다)

| | | | |
| --- | --- | --- | --- |
| 7 | 12 | 3 | 15 |
| 1 | 9 | 16 | 6 |
| 14 | 4 | 11 | 8 |
| 10 | 13 | 5 | 2 |

## 기본 규칙

1. 팀을 2~4개로 나눕니다. 팀마다 색을 정합니다.
2. 순서대로 한 팀씩 나와 **한 명이 40초 안에** 이륙 → 원하는 칸에 착륙합니다.
3. 착륙에 성공하면 그 칸에 **팀 색 색종이를 올려 점령**합니다.
4. **프로펠러 가드가 종이에 닿아 있으면 성공으로 인정**합니다. 빡빡하게 보면 게임이 안 굴러갑니다.
5. 칸을 벗어나거나 40초를 넘기면 그 차례는 넘어갑니다.
6. **가로·세로·대각선 4칸을 먼저 채우면 빙고**, 그 팀이 승리합니다.
7. 시간이 남으면 2빙고까지 갑니다.

### 뺏기 규칙 (넣으면 훨씬 재미있음)

- 상대 팀이 점령한 칸에 착륙하면 **그 칸을 빼앗습니다.**
- 단, 뺏기는 게임당 팀별 **2번만** 가능. (안 그러면 끝이 안 납니다)
- 뺏기 카드 2장을 팀에 주고, 쓸 때마다 반납하게 하면 관리가 쉽습니다.

## 진행표

| 시간 | 내용 |
| --- | --- |
| 0~5분 | 안전 약속 + 팀 나누기 |
| 5~10분 | 빙고판 깔기 (학생이 직접) |
| 10~15분 | 연습 비행 한 명당 1회 (점령 안 됨) |
| 15~40분 | 빙고 본게임 |
| 40~47분 | 기록 계산 + 2라운드 또는 결승 |
| 47~50분 | 시상, 정리 |

## 수학 버전 - 수학학원이라면 이걸로

칸에 그냥 숫자 대신 **답**을 써 두고, 선생님이 문제를 외칩니다.

### 구구단 빙고

칸에 곱셈 답을 씁니다: 12, 18, 24, 28, 35, 42, 48, 54, 56, 63, 72, 81, 16, 27, 36, 45

- 선생님: "6 곱하기 7!" → 팀은 **42가 적힌 칸**에 착륙해야 점령.
- 틀린 칸에 착륙하면 점령 실패 + 그 차례 종료.
- 답을 먼저 찾는 눈과 조종 실력이 둘 다 필요해서 실력 차가 덜 납니다.

### 다른 과목 버전

| 버전 | 칸에 쓰는 것 | 선생님이 외치는 것 |
| --- | --- | --- |
| 분수·소수 | 0.5, 0.25, 0.2, 0.75 ... | "2분의 1!" |
| 큰 수 | 1200, 3500, 4800 ... | "300 곱하기 4!" |
| 약수·배수 | 12, 18, 24, 36 ... | "6의 배수 아무 칸!" (여러 정답 허용) |
| 영어 | apple, water, school ... | 단어 뜻을 한국어로 |

## 상황별 조정

| 상황 | 이렇게 |
| --- | --- |
| 드론 1대, 학생 많음 | 팀당 조종 1명 + 기록 1명 + 코치 1명, 매 차례 역할 교대 |
| 공간이 좁다 | 3 x 3 판(9칸), 한 줄 3칸이면 빙고 |
| 시간이 남는다 | 5 x 5 판으로 키우고 2빙고 승부 |
| 실력 차가 크다 | 잘하는 학생은 **출발선을 1m 뒤로** |
| 저학년 | 뺏기 규칙 빼고, 40초 제한 없애기 |
| 너무 빨리 끝난다 | "대각선 빙고는 2줄로 인정" 같은 보너스 규칙 추가 |

## 드론을 못 쓸 때 (플랜 B)

같은 빙고판에 **종이비행기** 또는 **콩주머니**를 던져 점령합니다. 규칙이 그대로라 바로 전환됩니다.

## 안전 기본

1. 사람 쪽으로 날리지 않는다.
2. 떨어진 드론은 선생님이 줍는다.
3. 내 차례가 아니면 벽 쪽에 선다.
4. 실내에서는 프로펠러 가드를 항상 단다.
